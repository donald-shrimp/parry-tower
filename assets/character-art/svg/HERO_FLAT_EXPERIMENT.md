# SVGフラット騎士 v1 — 手描き比較案
本SVGは2026-10-18に会話内で作った`hero_flat_knight.svg`をもとに、背景の白い矩形だけを除いた7グループ構成の試作品。元画像の自動トレースではなく、簡単な図形を手で配置した実験案。

- `?art=flat`: 描画のベースはこのSVG。JavaScriptが`<g id="...">`を画像レイヤーへ分離し、既存Canvas 2Dの描画系へ合成する。
- `?art=svg`: 以前の不採用12パーツSVG。混同しないこと。
- `?art=prototype`: 以前のCanvas描画試作。値がなければ従来描画。
- 画像生成の参照画そのものの忠実な模写ではない。正式な採用画像 `svg-base-approved.png` は未登録なので、このSVGは**候補・実装検証用**。採否判断前に登録を偽らない。
- ロード失敗時は既定表示に戻す。パリィの時刻・判定・保存データは変更しない。
- 盾と剣は元図のグループごと可動する。今後正式採用するなら腕との連結や支点設計を精査する。
- GitHub Pages既定のmainには反映されない。Draft PR #28のみ。
