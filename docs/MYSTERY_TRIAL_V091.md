# v0.9.1 — 血闘に現れる謎の先行遭遇
## 概要
4F/8Fの血闘を選択した場合、**50%**で現在地より**2エリア（約20階）先**のそのエリア固有の通常敵が、精鋭として現れる。

- **戦闘中の名前は「？？？」**、開始表示は UNKNOWN ENCOUNTER。特殊なフルスクリーン演出は加えない。
- **見た目・攻撃モーション・拍パターン**は未来の敵そのまま。**HPと攻撃力**は現在のフロアの精鋭倍率（HP×1.3/攻撃×1.15）で計算し、未来フロアの強さで殴られないようにする。
- 謎の敵の**先行遭遇・討伐は図鑑に登録しない**。稽古も開放しない。元の敵データ・図鑑の50枠は変更しない。
- 初めて本来のエリアで遭遇したときに正規の名前を出し、図鑑へ通常登録する。
- 出現しない50%は従来どおり現在のエリアの精鋭。血闘の塔貨14枚、通常スキル報酬、レリック抽選・コンボ維持は変えない。
- **61～80F、81F以降**は2エリア先の未登場ゾーンを定義しないため、従来の精鋭戦にする。レア敵・ボス（とくに終刻の王）の先行出現はなし。

## 実装・互換性
敵データ API `foreshadowTrialForFloor` が予告用の一時的な戦闘インスタンスを作る。元の `byId` と `codexEntries`、既存セーブの構造は変えず、`recordEncounter` と `recordDefeat` も `preview` を拒否する二重防御とした。`game.js` は通常の血闘フローの入口でのみ抽選し、図鑑保存をスキップする。
