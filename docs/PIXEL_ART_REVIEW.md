## 加工内容

画像生成は使用していない。主人公の構え1枚、騎士の構え/補修布2枚、他の敵の構え13枚と打ち込み4枚、計20原画から60枚を作成。共有原画を使う色違いも含め全立ち絵をカバーする。

| 候補 | 原画上の1ブロック | キャラ共通の最大色数 |
| --- | --- | --- |
| 細かめ | 6px | 64色 |
| 標準 | 10px | 40色 |
| レトロ強め | 14px | 24色 |

整数グリッドへ余白を足してBOX縮小、軽い輪郭強調、median-cutによる減色、透明度の二値化（閾値80）、最近傍拡大を行う。構え/打ち込み/補修布はキャラ内で同じパレットを共有し、切り替え時の色の変化を抑える。元の寸法と座標を保ち、既存のマスク/関節/調整値を利用する。

候補は `assets/character-art/pixel-candidates/` のみへ出力。manifestに設定、原画と候補のSHA-256、寸法、色数を記録する。再作成にはPython/PillowとNodeが必要：

```powershell
python scripts/build-pixel-art.py
```

`assets/pixel-art-preview.js` は動作レビューだけが読み込む任意のURL指定モジュール。`pixelStyle=fine|balanced|retro` の場合だけ候補を使う。index/dev/工房はこのモジュールを読み込まず、ゲームの既定画像は原画のまま。採用や保存のボタンは設けていない。
