# v0.5.8 — 新スキル6種・シナジー6種・運命の封印

## 全体方針

既存18スキルから**24スキル**、シナジー5種類から**11種類**へ拡張。初期装備用の個別解放、4択の戦利品、従来の恒久強化、旧セーブキーを維持する。

### 実装上の補足

- 拍動のJUST連続数は通常パリィ・ガード・ミスで切れる。既存のJUSTウィンドウ・BGM同期は変更しない。
- 過充電・氷結のパリィ回数は非連続でも蓄積。過充電は**とどめの成功パリィもカウント**し、敵を倒した場合は次の生存敵で発動するまで蓄積を保持。
- 氷結の加護は防御の前に軽減し、その残りを既存障壁で吸収。氷鏡のダメージは「ガード反射」と同じく吸血対象外。
- 不屈はHPダメージで発動。シナジー成立中は、障壁が破壊されてHP無傷でも発動する。1回の被弾でストック重複しない。
- 血の渇望の回復と吸血の回復は1成功パリィにつき1回ずつ発生し、**実際に増えたHPだけ**次の反撃に加算。蓄積上限は基礎攻撃力×3.0/3.5/4.0/4.5。回復が無い（HP満タン等）と次の蓄積は0。前回の蓄積は次の反撃で1度だけ消費され、追加攻撃の連鎖発火は発生しない。
- 成功パリィ由来の拍動・過充電・王の一撃は、既存の吸血リワークが対象にしている実ダメージ合計へ含める。オーバーキルは含まない。
- 同じパリィ内の追加攻撃からさらに追加攻撃を呼び出す仕組みは作らない。
- 各スキルの進捗（連続JUST・過充電・氷の加護・王の一撃・血の渇望・不屈）はBUILD欄で表示する。

## 🔮 運命の封印

恒久強化ショップに独立した **「運命の封印」** タブを追加。購入できるのは封印枠（1〜4枠）であり、スキルの封印・解除は無料。

| 封印枠 | 追加費用 |
| --- | ---: |
| 1 | 25 ✧ |
| 2 | 60 ✧ |
| 3 | 120 ✧ |
| 4 | 220 ✧ |

- 任意の既知スキルを最大4種類まで封印し、ラン中の戦利品の全抽選（引き直し含む）から除外する。
- 初期装備**未解放**のスキルも封印できる。**初期装備中**のスキルは封印不可。封印中のスキルを初期装備することも不可。
- ショップはタイトルとゲームオーバー画面からのみ開く。出撃中は変更できない。
- スキルカタログ `SKILLS` から動的に列挙するため、追加スキルも自動で封印選択肢に登場する。
- 運命の封印はラン開始時に抽選除外のスナップショットを取得する。保存キーは旧来と同じ `parryTowerPermanent_v1` で、既存データに `sealSlots`、`sealedSkills` を追加するだけ。古いデータでこれらがない場合は0枠・空配列。
- 破損セーブからの復元時は上限、重複、ID、装備との競合をチェックする。カタログから削除されたスキルは封印枠を消費しない。
- 稽古場は封印設定に影響されない。開発者ページは封印を読めるが、永久保存しない。
- 戦利品の抽選重み（既取得スキル1.17倍）は**変更しない**。封印と初期装備の効果を見てから調整する。

## テストの要点

`tests/progression.test.js` と `tests/game-smoke.test.js` で、旧データ互換、封印枠の段階購入・無料切替、ランごとの抽選除外、装備との競合、各スキルの発動回数と実ダメージ・実回復、全シナジー、開発者ページの隔離を検証する。実ブラウザのプレイ感と高階層の難易度は別途試遊で判断する。
