# パリィの塔 v1.0.0

音楽と効果音、保存、戦闘、画面の仕組みを整理した版です。既存のセーブデータを引き続き使えます。敵の攻撃タイミング、パリィの判定幅、ダメージ、曲、立ち絵・モーションの変更はこの版に含みません。

本編とDevで曲の選択・再生を共通化し、音声時計と予約の管理を分離しました。保存の読み書き、戦闘の計算、ショップ・図鑑・報酬・部屋の表示も、担当ごとに分けました。アセットの読み込み順は一つの一覧にまとめ、JSやCSSの内容に合わせて更新用URLを生成します。
