# v0.5.3 — 階層・精鋭/レア・図鑑・闘技場（試作）

この変更は既存v0.5.2の戦闘感覚を維持し、周回の目的を追加するための第1段階。

## 階層構造

10階ごとにテーマを持つ4エリア。41階以降はエリアが循環し、敵のステータスは引き続き上昇する。

| 階層 | エリア | 主な敵 | 主な攻略 |
|---|---|---|---|
| 1-10 | 忘れられた地下墓地 | スライム、騎士、亡霊 | 基本的な拍・予備動作 |
| 11-20 | 鉄血の兵舎 | 番兵、騎士、紅刃の剣士 | 重い剣戟と連撃 |
| 21-30 | 残響の礼拝堂 | 亡霊、詠み手、暗殺者 | 休符と裏拍 |
| 31-40 | 歪んだ時計塔 | 時計仕掛け、番兵、剣士 | 複合リズム |

各エリアの1・2・9階は原則固定、3・4・6・7・8階は限定プールから抽選。5階はエリアボス、10階はその精鋭ボス。9階も保証精鋭。これは全エリアの繰り返しに適用。

## 精鋭とレア

- 通常抽選がある8階以降は精鋭が**12%**で登場。HP×1.3、攻撃力×1.15。固定9階と各エリア10階は精鋭確定。
- レア敵は6階以降の通常候補階で**8%**。直近出現から最低4階空ける。固定階とボス階には出現しない。
- レア2種：黄金の音叉（欠片+8）、宝石スライム（欠片+12）。通常より少し高いHP。精鋭撃破は欠片+2。
- 討伐ボーナスは**塔で倒した瞬間**に既存の魂の欠片残高へ加算し保存する。ブラウザを閉じても失われない。ラン終了時の通常報酬は従来どおり。したがってボーナス二重加算禁止。
- 成長は10階までは従来係数（HP×1.18/階、攻撃×1.09/階）を使い、11階からHP×1.075、攻撃×1.045とする。個体倍率はそのあとに乗算。
- レア/精鋭の区別は出現表示・名前・金色/赤いオーラで表現。新規モンスターのグラフィックは既存モーションを利用した暫定デザイン。

## 図鑑と闘技場

- 図鑑は**塔で倒した個体のみ**登録。通常と精鋭は別枠、レアも別枠。
- 初回討伐階・累計討伐数を記録。未発見個体は非公開表示。
- 登録した敵は図鑑の「闘技場で戦う」から再戦可能。稽古場（無敵・常時利用可能）とは別の、HPが減る通常戦闘。
- 闘技場は敵の基本ステータス（ボスは5階相当、その他は1階相当）を使用し、挑戦者はラン開始時の状態。
- 闘技場の勝敗は**魂の欠片・図鑑登録数・到達階層に影響しない**。同じ相手へ何度でも再挑戦できる。
- 既存の恒久強化セーブキー \`parryTowerPrototype_v1\` をそのまま使い、図鑑は別キー \`parryTowerBestiary_v1\` に独立保存。旧ユーザーの図鑑は空から開始（過去の討伐履歴は追跡されていなかったため）。

## 戦闘保護規約

BGM/譜面の基準は \`AudioContext.currentTime\`。パリィ判定はジャスト±11ms、通常±31ms、先行100msを変更しない。既存 \`syncAttackClock\` / \`scheduleScore\` / \`tap\` の時間計算には手を入れない。敵種の追加は \`kind\` を既存5種に紐づけ、独自の拍配列だけを追加する。
