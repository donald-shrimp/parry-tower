# 戦闘ポーズ・可動設計ガイド — 全キャラクター必須

このガイドは **ゲーム内で戦うキャラの立ち絵を作る前に必ず読む**。適用対象は画像生成 → 静止SVGトレース → パーツ分割 → モーション実装の全工程。キャラ別仕様より優先するのは「装備と関節が無理なくつながっていること」であり、色や顔など採用済み意匠は維持する。

## 最重要原則：絵を描く前に可動の出発点を決める

- **静止画の基準ポーズ＝攻撃直前の待機姿勢（combat-ready idle）**。剣をだらりと下げた立ち絵は採用しない。攻撃・防御の準備ができており、隙の少ない構えが見た目に分かること。
- 待機姿勢の時点で、盾・剣・爪・杖・突起などの攻撃部位が敵のいる方向に対応している。
- 画面内の対峙方向を先に確認する。**主人公は画面左側に立ち、敵は画面右側にいる**。敵は基本的にその逆向き。左右の手を言葉だけで指定して鏡像ミスを起こさず、「画面右／左」で見える位置も必ず記載する。
- 待機状態に限らず、**予備動作→攻撃→接触→反動・戻り**を想定してポーズを設計する。
- イラストを先に作って後から武器だけ回して済ませない。**肩、肘、手首、握り、武器の接続が動作全体で成立**すること。
- 上記のため、体全体のパーツ数が増えてもよい。図形20〜30個は見た目の目標であり、**関節を消すための上限ではない**。

## 立ち絵を生成するときに明記する内容

キャラ別指示書に下の必須フィールドを置き、画像生成エージェントは省略しない。

| 項目 | 指示の要点 |
| --- | --- |
| 敵の方向・立ち位置 | 左右どちらを向いて、どちらに攻撃するか |
| 基準ポーズ `idle` | 構え・武器先端・視線・重心・脚の開き |
| 守備 `guard` | 盾・腕・肩・胴のどこがどの方向へ動くか |
| 予備 `windup` | 打撃開始前に武器と上腕／肘をどこへ引くか |
| 攻撃 `strike` | 肩からの振り、肘の伸び、握りと武器が一体で動く軌道 |
| 反動 `recover` | 接触・被弾後にどんな姿勢を経由してidleへ戻るか |
| 可動点／パーツ | 肩、肘、手首、股関節、武器の握り、盾の握りの位置と重なり順 |

## PNGからSVG化する場合の手順

1. **承認した戦闘待機PNGをそのまま静止SVGへトレース**。元画像の比率・輪郭を維持し、手描きの目測図形で再構成しない。
2. PNGと静止SVGを等寸で重ね、顔・肩・肘・武器の握り・盾の外形・剣先が一致するまで清書する。**ここで人間が採用判断**。
3. 静止SVGを分割するときは、頭・胴・左右の上腕・左右の前腕・手・剣・盾・脚・マントを必要に応じ独立させる。**武器単体を手首から回転させるだけのリグは禁止**。
4. 分割の結果、静止時に欠けた隙間を埋めるためだけの補完（肩・肘の下部など）を追加し、**基準姿勢を合成した絵が清書SVGと一致**することを確認。
5. 接触時の盾・剣先位置は既存ゲームの映像上の着弾位置に合わせる。**Web Audio同期、判定時間、ゲームロジックは変更しない**。
6. `idle`, `guard`, `windup`, `strike`, `recover` の5場面をそれぞれ同じ縮尺でレンダリングし、**手から柄が離れないか、肩が抜けないか、関節だけが不自然に回っていないか**検証する。
7. 比較モードは既存Draft PR #28に保持し、新しいポーズが承認されるまで旧トレース版（`?art=trace`）を上書きしない。

## キャラ別に必要な基準姿勢

| キャラID | 待機中の構え（実装前に詳しい指示を補う） | 主に動かす部位 |
| --- | --- | --- |
| `hero` | **敵がいる画面右へ盾を構え、剣は頭・肩の高さで斜め上。肘を曲げて反撃準備** | 両肩、両肘、剣の握り、盾、腰 |
| `knight` | 剣を斜め前上に置き、振り下ろしの予備動作が自然に始められる | 肩、肘、剣 |
| `slime` | 体を前後に寄せ、打点側のゲル突起が既に相手を向く | 核、外皮、突起 |
| `rogue` | 低く構え、短剣を胸横に引いて突き出せるように | 肩、肘、手首、腰 |
| `duelist` | 二刀を左右で異なる高さに構え、連撃の順番がわかる | 左右の肩と肘、両剣 |
| `wraith` | 爪を前に突き出しかけた姿勢で、腕とローブを分離 | 肩、肘、爪、裾 |
| `cantor` | 両掌を胸の前で差し出し、術式が腕と連動する | 肩、肘、手、術式 |
| `sentinel` | 大盾を前方に立て、剣を後方で引き上げる | 盾腕、剣腕、腰 |
| `clockwork` | 拳または機構武器を正面へ構え、腕関節のピストンが分かる | 肩軸、肘軸、ピストン |
| `guardian` | 大剣を肩の上または斜め上に置き、全身を使う大振りの予兆を作る | 両肩、肘、体幹、脚 |

## 合否ゲート

- [ ] **待機時に武器・盾・攻撃部位が既に構えられている**
- [ ] 動作が手首だけではなく肩・肘・体幹を使って成立
- [ ] 各装備の持ち手と身体のつながりが自然
- [ ] 待機・予備・振り・接触・戻りで武器先端・盾輪郭がフレーム内
- [ ] 静止SVGとPNGの輪郭・位置関係を確認済み
- [ ] 96px / 128px程度でも構えと攻撃方向が伝わる
- [ ] 実機で見られない場合は未検証と明記し、「完了／完成」と主張しない

注: アニメーション用に**複数の姿勢の資料画像を勝手に生成する必要はない**。まず基準ポーズ1枚のPNGで静止トレースを行い、必要な場合だけキー姿勢の追加資料を別工程で人間に確認する。
