# キャラクターアート制作 — 確定した工程のチェックリスト

入口は [README](./README.md)、実施手順は [PIPELINE](./PIPELINE.md)、画像トレースと可動化の技術詳細は [TRACING_AND_RIGGING](./TRACING_AND_RIGGING.md)。

## 進める順序と承認ゲート

1. **原画のポーズを設計**：敵の向き・武器の構え・肩肘の動き・接触位置を決める。[POSE_GUIDE](./POSE_GUIDE.md)
2. **SVG用のフラットな戦闘待機PNGを1枚生成**：ユーザーへ提示して**原画の採用を待つ**。未採用なら以降へ進まない。
3. **採用されたPNGを原寸で保存**：`assets/character-art/references/<id>/svg-base-approved.png`、寸法とSHA256を`notes.md`に記録。登録不能なときは未登録と明言。
4. **同じ原画をトレースし静止SVGを清書**：色境界・輪郭を直接取得。元PNGと同じサイズで重ね、96px・128pxの表示も確認して**ユーザーの静止SVG採用を待つ**。
5. **静止SVGからマスクでパーツ抽出**：固定本体から腕・武器・盾の領域を消し、可動側へ分配。隠れていた肩肘の裏だけ必要最低限補完。idleで元絵と一致するまで修正。
6. **親子関節を付け動く試験モードを作る**：肩→肘→手と握り武器、または敵に合わせた伸縮・突きなど。敵の当たり判定・Web Audio・戦闘時間は変更しない。
7. **ゲーム画面のモーションを確認する**：待機、予備、攻撃、接触、回復、必要に応じガード。元描画の復帰・96pxと128px表示・スマホ幅・クリップも検証する。ユーザーが動作を採用したら仕様を確定。
8. **Draft PR #28へ作業履歴・試験URL・テストを記録**。本番へのマージはユーザーの明示指示が必要。

CI成功と目視合格は別。実ブラウザを見ていないときはそう報告する。**各工程の承認前に次工程の完了を勝手に宣言しない。**

## 主人公の正式仕様（2026-10-18承認済み）

主人公は、肩の高さに剣を構えて胸前に盾を保持する戦闘待機、原画トレースの静止SVG、肩と肘の可動が採用された。**逆回転−360度が主人公の反撃の正式仕様**。

- 標準プレビュー：`?art=ready` → **−360°**
- 比較：`?art=ready&spin=360`（正回転）、`?art=ready&spin=legacy`（小振り）
- この正式採用は主人公だけ。敵へ一律に−360度を流用しない。敵の`ctx.scale(-scale,scale)`による鏡像も考慮。
- 主人公の元PNGはGitHubへ未登録。過去の128×120px縮小コピーを使わない。静止SVGとランタイムは[READY_POSE](../../assets/character-art/tracing/hero/READY_POSE.md)を参照。
- このブランチはまだDraft PR、`main`未反映。

## 再発防止

- 図形を目測で並べて原画を模写しない。原画の色と輪郭を直接トレースする
- 設定画の縮小コピーで「承認済み原寸PNG」の代わりにしない
- 静止SVGの見た目が合格する前にパーツ分割とゲーム実装を始めない
- 固定背景に盾や剣の画像が残ったまま可動部品を描かない
- 剣や爪だけを手首の1点で回して攻撃を表現しない
- 縁が切れてもviewBox・pivot・変換範囲の検証を省略しない
- すべての敵に同じモーションを当てはめない
