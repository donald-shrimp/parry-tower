# 残響の詠み手 / `cantor`

> 共通: [README](../README.md) → [STYLE_GUIDE](../STYLE_GUIDE.md) → 本ページ。SVG担当は [SVG_SPEC](../SVG_SPEC.md) と採用画像も必須。

## 役割とデザインの核

亡霊系の術式を唱える魔術師。腕と掌のエネルギーを攻撃の軌道として読む。

## 外観の固有要件

- **シルエット**: 幅広い袖、尖ったフード、浮遊ローブ、掌の前の独立した小ルーン。遠目でwraithと違う『術者』の輪郭。
- **配色**: 深紫、くすんだ藤色、青白い掌光、淡い金属の小記号。
- **可動パーツ設計**: フード、胴と肩、右左の袖、内部の手、ローブの裾、手前のルーン3点以内、掌のコア。
- **攻撃とアニメーション**: 準備中に袖と掌を持ち上げ、魔力を凝縮させて前方へ放つ。ルーンは身体と別レイヤーで動かせる。
- **避ける**: 巨大な読みにくい魔法陣、背景全体を覆う霧、物理の爪が主役になること、魔法文字の細密化。
- **追加の判断基準**: 星屑の詠み手向けに小さな星の点光を追加できる構造。
