# 塔の亡霊 / `wraith`

> 共通: [README](../README.md) → [STYLE_GUIDE](../STYLE_GUIDE.md) → 本ページ。SVG担当は [SVG_SPEC](../SVG_SPEC.md) と採用画像も必須。

## 役割とデザインの核

宙に浮き、腕や爪を伸ばして攻撃する霊体。物理騎士と違う予兆を持つ。

## 外観の固有要件

- **シルエット**: フードと細く長いローブ。下端は脚に分かれず、2～3本の裂けた布へ。肩は狭く、片腕が細く前に伸び、指先は爪状。
- **配色**: 暗い群青、青紫、霧色、青白い細い発光、目だけ明るいシアン。
- **可動パーツ設計**: フード・頭の暗部、胴ローブ、肩・腕、伸びる前腕、爪、浮遊する裾。透明効果より不透明な色面を中心に。
- **攻撃とアニメーション**: 溜めで身体が浮き上がり、爪先が伸びて盾へ近付く。足がない姿勢のため腰より下の分割は布片単位。
- **避ける**: リアルホラーの生首、複雑な煙や霧で輪郭を隠すこと、マントと腕の癒着。
- **追加の判断基準**: 詠み手との差は、術式よりも爪と身体の輪郭を主役にすること。
