# 紅刃の剣士 / `duelist`

> 共通: [README](../README.md) → [STYLE_GUIDE](../STYLE_GUIDE.md) → 本ページ。SVG担当は [SVG_SPEC](../SVG_SPEC.md) と採用画像も必須。

## 役割とデザインの核

暗殺者系の二連撃・双剣を明確に識別させる派生型。

## 外観の固有要件

- **シルエット**: 軽装の細身剣士。両手に長さの近い2本の刃、片方は前、もう片方は斜め上へ構える。身体と腕で鋭いX状の余白。
- **配色**: 暗いワインレッド、ローズピンク、鉄黒、鈍銀。赤い刀のアクセントは小面積でも目立たせる。
- **可動パーツ設計**: 兜または薄いフード、胴、両腕・両手、主剣、副剣、左右の脚、短い腰布。刀と握り手は別パーツ。
- **攻撃とアニメーション**: 一撃ずつ左右の手を交互に前へ出す。どちらが次に攻撃するか分かるよう、刀を交差させすぎない。
- **避ける**: 一本しか見えない二刀、過剰に長い刀、重い盾、真正面で武器が重なる構図。
- **追加の判断基準**: 白銀の双剣士に転用しやすい機能的シルエットを重視。

## SVG制作担当への指示（採用画像がある時だけ）

1. 採用済み参考画像 `assets/character-art/references/duelist/approved.png` の**実際の絵を確認**する。なければ作業せず、ユーザーへ採用画像の添付を依頼する。

4. [SVG_SPEC](../SVG_SPEC.md)に従い `assets/character-art/svg/duelist/` へSVGパーツと `manifest.json` を出力。ブラウザでレンダリング・比較テストする。
