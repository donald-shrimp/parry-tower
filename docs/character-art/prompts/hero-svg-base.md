# 主人公（hero）SVG下絵生成プロンプト v2

これは **画像生成エージェントがそのまま使う完成プロンプト**。設定画・三面図ではなく1枚のゲーム用立ち絵を作る。キャラ固有仕様は [hero.md](./hero.md)、共通規約は [SVG_BASE_GUIDE](../SVG_BASE_GUIDE.md) を優先する。

## 画像生成用プロンプト（そのまま使える本文）

ゲーム『パリィの塔』の主人公「パリィの騎士」を、**後からパーツ分割SVGに模写するための、簡潔な2Dゲーム用立ち絵**として1枚描いてください。

**1体だけ、全身、1ポーズ**。正面より少し斜め（3/4）の自然な待機姿勢。2.5〜3.5頭身、小柄だが頼りなくない「盾で受け、剣で反撃する」騎士。完全に隠れた顔の兜、青灰・鈍い銀の装甲、深い青の短めのマント、わずかな真鍮色、兜の目元に小さなシアン。手前の腕に**金色の縁取りがある中くらいの青い多角形盾**、もう一方の手に**短い片手剣**。盾の模様は大きな単純な紋章1つまで、鎧の重なりも大きな板に限定してください。

最も重要なのは **ゲーム内の小さなサイズで読みやすい輪郭**です。兜・胴鎧・肩・上腕・前腕・手・盾・剣・両脚・マントは、それぞれSVGパーツとして分けやすい境界が見えること。剣と盾は身体から少し離し、互いにも重ねすぎないでください。盾の全周、握る手、剣の鍔と先端が見えること。盾や剣が画像の端で切れたり、マントや体で不自然に隠れたりしないようにしてください。

塗りは明快なフラットセル塗り。主に**4〜6色程度、各パーツの影は1段階**。輪郭線は太めで安定、形は大きな閉じた面。細かな金属反射、細密な鎖、編み目、複雑な段差、布の大量の皺、装飾文字、複雑な紋章は禁止。飾りが減っても、盾と兜と青いマントで主人公だと分かるように。

**構図に必須の制約**: 頭頂から両足・盾の下端・剣の先端・マントの端まで全て画面内に入れ、キャラと武器・盾を含む外側の輪郭と画像の四辺との間に**15%以上の安全余白**を取る。中央に1体だけ配置する。背景は完全透明、難しければ白無地。床、影の演出、光のエフェクト、文字は不要。

**絶対に出さないもの**: 設定資料シート、三面図、複数ポーズ、別角度、武器の拡大図、パーツ分解図、色見本、ラベル、吹き出し、背景装飾、UI、立体風CG、写実的な質感、画面からはみ出た武器。

成果物は**SVGではなく1枚のPNG画像案**。画像を提示し、ユーザーの採否判断を待ってください。勝手にGitHubへアップロードしたり、SVGへ変換したり、ゲームへ実装したりしないでください。

## 提示前のセルフチェック

- 1体・全身・背景なし・文字なし・別図なし。
- 盾の外形・紋章・握り手、剣の先端、マントの端が欠けていない。
- 外側に余白がある。盾が巨大すぎたり、腕・剣が体と癒着していない。
- 96px程度でも「盾を持った小柄な騎士」と判別できる。

## 画像採用後

ユーザーが承認した場合だけ、`assets/character-art/references/hero/svg-base-approved.png` に**原寸の採用画像**を登録する。今回の旧設定画からの128×120px切り出しは本番SVG下絵としては使用しない。次の担当は [SVG_SPEC](../SVG_SPEC.md) に従って新規SVGを制作する。
