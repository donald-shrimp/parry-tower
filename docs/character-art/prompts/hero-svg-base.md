# 主人公（hero）— 幾何学的フラット立ち絵プロンプト v3

**現在の主人公はデザイン・可動・逆回転−360°を採用済み。このプロンプトは再生成の指示があった場合のみ使用する。**

**画像生成担当は [POSE_GUIDE](../POSE_GUIDE.md)、[FLAT_VECTOR_SPEC](../FLAT_VECTOR_SPEC.md) と [SVG_BASE_GUIDE](../SVG_BASE_GUIDE.md) を必ず読んでから実行する。**

## 画像生成用の完成プロンプト（ここを最優先で画像にする）

ゲーム『パリィの塔』の主人公である「盾と剣を持った小柄な騎士」を、**幾何学的フラットベクターデザイン**で描いてください。

**これはアニメイラストでも美しい立ち絵でもなく、少数の基本図形と一定の線幅だけで構成した2Dキャラクターピクトグラム**です。インディーゲームに登場する、素朴なボードゲームの駒・シンプルなベクターマスコットに近い絵柄。**絵心がなくてもSVGの多角形と線だけで再現できること**が最重要です。

**構成する図形**:
- 兜＝単純な丸みのある多角形と台形、目は1〜2本の短い線。
- 胴体＝台形1つ。肩・腕・脚＝長方形・角丸四角形・小さな多角形。
- マント＝暗青色の大きな多角形1つ。複雑な波打ちや布の折り目を描かない。
- 盾＝外形が全部見える五角形1つ。金縁は太い輪郭線1本。紋章は原則描かない。
- 剣＝細長い多角形1つ、短い横線の鍔1つ、棒状の柄1つ。先端を完全表示。
- 独立した部位として、頭・胴・左右の腕・左右の脚・盾・剣・マントの境界を認識できるようにする。

**図形数は全身で概ね20〜30個**、大きな色面は**最大4色**（銀灰、青、鈍金、濃紺）＋必要ならアクセント1色。輪郭はほぼ黒に近い濃紺1色で全パーツ同じ太さ。**各部位を原則1色でベタ塗りし、影は一切付けない**。

全身は2.5〜3頭身。**画像の左に立つ主人公が画面右の敵を向く、構えのある戦闘待機姿勢**。盾は**画面右の胸の前に構え、外周が見える**。剣は**画面左の肩〜兜の横へ持ち上げ、刃先を斜め上に向ける**。剣を握る手は肩の近く、肘は明確に曲がり、肩を起点に剣を右の敵へ振れる。どちらも構えており、ぶら下がっていない。足元は少し前後に踏ん張る。強いパースは付けない。**兜・青いマント・青と金の盾・白銀の鎧・シンプルな剣の既存の意匠を維持**する。

画像は1体だけ、中央配置。頭頂・足先・剣先・盾の下端・マントの外周がフレーム内で欠けないように、外側に15%以上の白い余白。背景は白無地か透明。文字・ロゴ・補助図版は描かない。

**絶対に禁止**: セルシェーディング、塗りの影、金属光沢、装甲の立体的な陰影、ハイライト、グラデーション、質感、複雑な鎧の縁取り、ベルトの装飾、布の細かな皺、リアルな剣、宝飾品、豪華な紋章、三面図、装備アップ、パーツ分解図、複数ポーズ、3D感、アイソメ、写実、アニメの塗り。

**完成の目安**: もしこの絵をSVG化するなら、`<polygon>` `<rect>` `<circle>` と数本の短い線の組合せで十分だ、と感じられること。

画像を**1枚だけ**提示して採否を待ってください。採用前のGitHub登録やSVG制作はしないでください。

## 再生成が必要なケース

- 絵に影・光沢・グラデーション・何色もの装甲の明暗が付いた
- 兜や盾にたくさんの模様や線が入った
- 頭・胴・腕・盾が絡まって、分解するには高度なトレースが必要
- 盾、剣、マント、靴が欠けている
- **剣を下に下げている／肩と肘が直線で手首だけを回すしかない構図**
- 盾が胸の前で構えられておらず、攻撃に備えていない
- パーツを30個前後の単純な形として説明しづらい
