# 幾何学的フラットデザイン仕様（画像生成・SVG化共通）

**最優先目標：ポリゴン・長方形・円・簡単な曲線と一定幅の線だけで、見本のキャラクターを再現できること。**

画像生成エージェントは「きれいなイラスト」ではなく、**そのまま図形配置図としてSVGに起こせる平面図形の組み合わせ**を出力する。結果が複雑なら失敗。SVG担当も手描き風の装飾を追加してはいけない。

## 合格基準：具体的な制約

- **1キャラ・1方向・1ポーズ（[POSE_GUIDE](./POSE_GUIDE.md)の戦闘待機構え）。** 背景なし。白単色可。頭・足・盾・剣・マントがすべて見え、最外周から画像端まで約15%の余白。
- **輪郭と形**: 主として `rect`、`circle`、`ellipse`、`polygon`、**曲がりが少ない`path`**で構築できる形。各部位は単純な閉じた図形。
- **図形の目標**: 生成下絵は大きな色面のシンプルなデザインを優先（20〜30個程度は参考目標）。**トレースで抽出したSVGパス数には上限を設けない**。図形を減らして原画のシルエットや可動関節が壊れるなら削らない。
- **色数**: ベースの塗りは**4色まで**（鉄色、青、金、暗色など）＋必要なら目などのアクセント1色。黒に近い輪郭線は別枠。**1パーツ1色を原則**。
- **影・効果**: **影0段階**。グラデーション、ぼかし、テクスチャ、金属反射、面取り、光沢、アンビエントオクルージョン、布の細密なしわ、立体的な明暗、外側の影、エフェクトは禁止。
- **輪郭線**: 単一色、ほぼ一定幅、角丸は必要最小限。パーツ同士の輪郭線と境界線は太さを揃える。内部の線は最低限。
- **姿勢**: 装飾的な直立や武器を下げたポーズを避け、戦闘開始にふさわしい肩・肘・脚の構えを優先する。図形数が増えても関節の可動性を犠牲にしない。
- **視点**: 2Dの平面的な立ち姿。真正面〜ごく軽い横向きは可、**強い3/4パース、アイソメトリック、遠近による武器の短縮描写は禁止**。
- **装飾**: 盾の紋章はせいぜい大きな一本線や一つの図形。金縁なら線一本。鎧の装飾線・鋲・ベルトの小部品・歯車の細い歯・細かい紋章は省略。
- **小サイズ**: 高さ**96px**で図形の境界と装備が理解できること。輪郭の太さは小画面でも認識可能にする。
- **パーツの独立性**: 盾・剣・頭・腕・胴・脚・マントが、それぞれ別図形として切り出せる。腕や肩は盾に一部重なってもよいが、盾そのものの輪郭は欠けない。

## 画像のセルフチェック（失敗したら再生成）

1. 絵を**約30個の図形**に分解して短い文章で説明できるか（「兜＝半円＋台形」「盾＝五角形＋線」等）。
2. 影・グラデーション・立体感・金属の反射・細線の装飾が**本当にゼロ**か。
3. SVGを作る人が自由曲線を何十本も模写しなくて済むか。
4. 96pxの高さに縮小しても盾・剣・頭・脚が読み取れるか。
5. SVGにするときに各パーツを関節単位で分離できるか。

**「イラストの線を太くしただけ」「影を薄くしただけ」「彩色をフラットにしただけ」では合格にしない。**

## 参考：主人公を説明する図形の例

- 兜：ドームを単純な多角形1つ＋面頬の台形1つ＋目の線1〜2本
- 胴体：台形1つ
- 左右の腕：長方形やカプセル状の単純な形を各1〜2つ
- 左右の脚と靴：それぞれ1〜2つ
- マント：大きな単色の多角形1つ
- 盾：五角形1つ＋縁線1つ（複雑な紋章なし）
- 剣：細長い多角形1つ＋簡単な鍔の線1つ＋柄の棒1つ

**この例が意味するのは造形の仕組み**。説明のための図形数は目安であり、納得できる輪郭と可動性が優先。

## 「フラット」の判断

**OK**: サイン、ピクトグラム、ボードゲームの駒、シンプルな2Dベクターマスコットのような、はっきりした形と線。

**NG**: 美麗なSDキャラ、厚塗り、セルシェーディングされたアニメイラスト、金属鎧の立体反射、長い布ひだ、ドット絵化。

他資料の影1段、細密な鎧、3/4視点等よりこのフラット画風を優先。ただし機械的な図形数・色数の制約より、**ユーザーが採用した原画の造形と直接トレースによる再現性**を優先する。
