## 目標の取り違えに注意

**「ファンタジーイラストを少し簡素に描く」依頼ではない。**

**一様な太い線と少数の色の平面図形でできた、図形アイコンに近いキャラクターを作る**依頼。影はゼロ、3D情報もゼロ、紋章などの小装飾は基本ゼロ。SVGの`path/polygon/rect/ellipse`で素直に書けそうな形だけを描く。

## 必須条件

- 1体、1ポーズ、1方向、背景なし、文字なし、余分な資料なし。**ただし1ポーズは直立ではなく、[POSE_GUIDE](./POSE_GUIDE.md)で定める戦闘待機（combat-ready idle）**。
- キャラ全体を20〜30個程度の基本図形で説明可能なデザイン。単色面は4色まで＋アクセント1色、**輪郭は1色で一定線幅**。
- **影、グラデーション、テクスチャ、金属の反射、細かい皺、装飾、複雑な陰影すべて禁止**。「セル塗り」より厳格な「完全フラット塗り」と指定する。
- 盾・剣・足・マントの外周が欠けない。全装備を含む外周から四辺へ15%程度の余白。
- 遠近感のない2D正面〜ごく軽い横向き。強い3/4アングルは禁止。
- 盾、剣、腕、脚、胴体、頭、マントを別図形に分解できる。
- 実物のキャラを高さ96pxに縮めても職種を識別できる。

詳細・合否は [FLAT_VECTOR_SPEC](./FLAT_VECTOR_SPEC.md) に従う。

## 画像生成担当の最後の確認

1. 描いたものは「SDキャラのイラスト」ではなく「図形による平面のキャラクター」か。
2. 影・ハイライト・質感を一切使っていないか。
3. 盾の全周が見えるか。盾・剣・マント・脚の先端が画像枠で欠けていないか。
4. この絵をSVGにするのに、自由曲線だらけの模写が必要ではないか。
5. 図形予算（20〜30個程度）と色数予算（ベース4色以内）に概ね収まるか。

満たせない場合は「SVG化用下絵完成」と宣言しない。**画像をユーザーに見せ、採否を待つ。採用前のGitHub登録・SVG制作は禁止**。
