# フェーズB：SVG制作用「簡略立ち絵」の生成ガイド

> **設定画ではなく、ゲーム表示とパーツ分割のための清書用下絵を1枚生成する段階。**
> 多視点の資料を作らず、たった1体の全身立ち絵を1枚に描く。

## 必ず読むもの

[README](./README.md) → [STYLE_GUIDE](./STYLE_GUIDE.md) → 対象 `prompts/<id>.md` → このガイド。主人公は必ず [hero-svg-base.md](./prompts/hero-svg-base.md) の完成プロンプトを使用する。

## 画面構成（破れば作り直し）

- **1キャラ、1ポーズ、1枚絵**のみ。三面図・装備一覧・パーツ分解・表情集・文字・寸法・ラベル・ロゴは**禁止**。
- 中央配置、全身が収まる。**頭頂・左右の装備・盾の下端・剣の先端・足先まで欠けなし**。
- **四辺に最低15%程度の安全余白**。腕や盾、剣、マントを含む「最外周」を基準に余白を取る。画像フレームに触れるパーツは禁止。
- 背景は透過推奨、無理なら真っ白な単色。地面・光輪・攻撃エフェクト・台座・影の広がり・グラデーション背景は描かない。
- 2.5〜4頭身の低頭身、軽い3/4向き、ニュートラルな立ち方。激しいアクションポーズ、強い遠近表現、極端なパースは禁止。
- 盾・剣・両手・腕・胴体・腰・脚・マントの**境界が見える**。盾が胴体全体や肘を隠さず、剣が身体を横切らない。肘・膝・肩は自然に可動しそうな余地を残す。

## ゲーム向けの描画品質

- ベクターへ置換する前提で、輪郭は太さ一定、スッキリした閉じた面、単純な色ブロックにする。
- 大きな4〜6色を主として、部位ごとに影は**1段階程度**。超細密な模様、筆致、金属の鏡面反射、複雑な鎧の段差、過剰なハイライトは省略。
- 独立パーツとして切れる大きな形を優先。美術作品としての細密さより **縮小時の可読性と機能的な形** を優先する。
- キャラクターをゲームで縮小表示するため、生成画像を **高さ96px程度および128px程度**に縮小して判別できる構図が理想。

## 提示前に画像生成担当が自分で点検

1. 1体だけか。余計な図版・文字はないか。
2. 盾、武器、マント、足の先端が全て画面内で、最低限の余白があるか。
3. 腕・武器・盾・胴体がSVGパーツとして切り離せるか。
4. 96px相当でも盾持ち／剣士／亡霊などの役割が分かるか。
5. 色数と装飾を増やしすぎていないか。

条件違反なら画像生成をやり直し、ユーザーには合格した**1案**を示す（画像生成回数はモデルの制約内で）。**承認されるまでGitHub登録もSVG制作もしない。**

## 採用とファイル名

- 任意の意匠資料: `assets/character-art/references/<id>/concept-approved.png`
- **SVG制作の唯一の主参照**: `assets/character-art/references/<id>/svg-base-approved.png`
- 旧互換 `approved.png` が存在しても、SVG下絵としての採用を意味しない。人が下絵を採用して新ファイルを置く必要がある。
- 採用し直す場合は **`svg-base-approved.png` のみ上書き可**。過去の設定画は残し、採用メモに変更理由を書く。

SVG制作は [SVG_SPEC](./SVG_SPEC.md) の別ゲートで開始。
