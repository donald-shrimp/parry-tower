## 今回の判断

ユーザーは「スライム以外やり直し」「手も直ってない」と評価。5体の anatomy-v2 は不採用。黄色い宝石スライムは維持し、他5体をキャラデザ・画風を保ったまま構え全体から作り直す。現在の画像の手だけを反転/描き足す作戦は終了。今回はネット調査とポーズ候補の整理までで、新しい5体はまだ生成していない。

前回の「掌側を見せれば左手になる」というプロンプトと目視判定が誤り。掌/手の甲の見え方だけでは左右は確定できない。親指が手のどちら側に付くか、前腕の回旋、肘、肩、胴の前後関係を一貫させる必要がある。候補の透過・配置が検査に通っても作画の正しさを証明しない。

## 次の一回の進め方

まず番兵1体で、剣を低く引く構えを試す。元画像はキャラデザ参照としてだけ使い、古い肩上の構えを保存する指定は外す。ラフ段階で身体の向き・腕の帰属・左右の手を確認してから描き込む。5体まとめて生成してから「直った」と扱わない。実際の指・握りが確認できる大きさで提示し、ユーザーの評価を反映して残る4体へ展開する。

資料画像は元サイトで閲覧し、ダウンロードやGoogleスライドへの転載、imagegenへの画像投入はしていない。調査で見つけたAdorkaStockはAI利用不可のため画像生成参照として選定しない。

## ユーザー指定の盾資料と3D操作

ユーザー指定の [PICTURES・羽山淳一「剣と盾」の戦闘描写](https://genkosha.pictures/illustration/22031842780) を本文だけでなく実際の図で確認した。特に盾の裏側が見える06-7.jpgと07-7.jpgでは、盾の持ち手、拳、曲げた肘、肩までのつながりが分かる。盾は胴を隠しながら次の攻撃へ移れる位置にする。手首の向きは盾の面と持ち手から考える。図の転載・生成入力への使用はしていない。

[PoseMy.Artの剣盾シーン](https://posemy.art/app/?lang=en&scene=sword_pose8.pma) を実際に開き、カメラを正面・剣側・盾側後方へ回して観察。Bot Maleの盾側肘の回転リングをドラッグして角度を変更し、道具が手に追従しないことを確認して2回Undoで戻した。その後、右手へHand PosesのHolding an Axeを適用して握りを試した。現在のシーンは右手剣・左手盾であり、番兵の左手剣・右手盾をそのまま満たす完成ラフではない。拳と柄の接点、盾の固定方法も要調整で、プリセットの人体・握りが正しいと断定しない。

実操作のスクリーンショットはGit管理外の `test-results/pose-3d/shield-front.png`、`sword-side.png`、`shield-rear.png`。正面画像は握り変更前、残る2枚は変更後。3Dシーンの保存はPro案内が出たため未実施。アカウント作成・購入はしていない。ブラウザの検討タブは継続用に保持したが、独自の変更を再開URLから復元できるとは扱わない。

次の番兵は、盾で胴を覆う配置をまず定め、盾の持ち手→拳→手首→肘→肩を裏側からも確認する。剣の腕には盾や胴を切らずに振れる空間を残す。左手剣・右手盾へ変更する場合は手だけでなく全身・装備を一貫させる。3Dは空間構造の確認用であり、元の描き込んだ画風と装備デザインを置き換えない。今回も新しい原画の生成、Googleスライドへの追加、ゲーム/モーションの変更はしていない。
