# フィルタ塗り分け工房

<http://127.0.0.1:8002/filter-paint.html>

王の2姿勢から始める：<http://127.0.0.1:8002/filter-paint.html?starter=endking>

現在の王の開始例は、了承済みの黒鉄の冠・紫の裾の塗り分け。保存可能な正本は `assets/character-art/approved/endking/project.json`、本編の採用手順は [ADOPTED_ART](./ADOPTED_ART.md)。

元画像のRGBを単色で塗りつぶすツールではない。ブラシで編集するのは「どのフィルタを適用するか」という範囲指定だけ。元画像を保持し、色相・彩度・明るさ・コントラスト・強さをその範囲へ適用する。元のしわ、細かな色の違い、陰影を保って色味を変える。近い色を単色で埋める処理は設けていない。

## 使い方

1. 「画像を追加」でPNG/JPEG/WebPを選ぶか、キャンバスへドロップする。複数画像を追加でき、左上で切り替える。
2. 左でフィルタを選ぶ。「＋追加」で増やし、名前と色相などの数値を設定する。同じ設定を複数画像で共有する。
3. ブラシで適用範囲を指定する。囲み塗りなら輪郭へ順に点を置き、「囲みを塗る」で確定。消しゴムはその部分を元画像へ戻す。「戻す／やり直す」で修正できる。
4. 「編集データを保存」で、元画像・全画像の範囲・共通フィルタをJSONへ保存。「編集データを開く」で再編集できる。「PNGを書き出す」は現在選択中の画像だけを原寸で出力する。

フィルタは最大12個、画像は8枚まで。各画素へ1つのフィルタを指定する方式で、別のフィルタで塗ると範囲が置き換わる。ぼかしや複数フィルタの重ね掛けは今回の範囲外。透明な背景は塗らず、PNGの元アルファを保持する。黒い輪郭を保つ設定も変更できる。

「原画を見る」で効果なしの絵と比較。「塗り分けを表示」の色は範囲の目印で、完成画像の色ではない。背景の市松模様・カーソル・範囲の目印はPNGへ入らない。

## 拡大と操作

- 「全体を見る」、拡大率、＋/−でズーム。キャンバス上のCtrl＋ホイールも利用できる。
- 「移動」またはSpaceを押してドラッグで画面を移動。
- B=ブラシ、E=消しゴム、P=囲み、I=指定済みフィルタを選ぶ、H=移動。
- Enterで囲みを確定、Escで囲みを取り消し。Ctrl/Cmd＋Zで戻す、Shift付きでやり直す。Ctrl/Cmd＋Sで編集データを保存。
- ブラシの太さは元画像の画素単位。拡大しても同じ範囲を正確に指定できる。

## 下書きとファイル

操作後、このブラウザ・同じ接続先のIndexedDBへ1つの下書きを自動保存する。再度開くと復元する。別ブラウザや別ポートへは移らないため、色違いの案ごとに編集JSONをファイルで保存しておく。編集JSONに元画像も含むので、元のファイルを移動しても再編集できる。壊れたJSONやサイズ不一致の画像は現在の作業を置き換えずにエラー表示する。

1枚800万画素/辺8192px、合計2400万画素、追加ファイル1枚25MBまで。履歴はマスクのメモリ量と件数で制限する。ブラウザの下書きが利用できない場合はファイル保存を案内する。画像や編集データを外部サービスへ送信しない。保存先はブラウザの通常のダウンロード先。

王の開始例は現在の素材領域を引き継ぎ、共通の調整可能なフィルタを4個用意する。前回の3色ランプによる加工PNGを読み込んで上塗りする方式ではない。元の金色の原画へ効果を掛けるので、塗り分けと色の数値を独立して直せる。構えと振り下ろしでフィルタは共有し、範囲は個別。

開始例の再生成（Python/Pillow/NumPy）：

```powershell
python scripts/build-filter-paint-starter.py
```

工房はHTML/JSだけで動く。既存8002サーバーの再起動は不要。ゲーム用PNG、モーション、手動ポーズ、保存JSONへ書き込む機能は設けていない。ゲームへの反映は書き出し画像/編集データのレビュー後に行う。

## 検証

`node --test tests/*.test.js`。coreでは陰影・微細色差・原アルファ・黒線/元入力の不変、適用範囲だけの合成、透明画素を無視するブラシ/囲み、JSON検証、画像間の独立マスクと共有フィルタ、Undo/Redoを検証する。

ブラウザーで任意PNGの追加、ブラシ、囲み、数値編集、Undo/Redo、マスク/原画表示、編集JSON書出し/読込、下書き復元、PNG出力を実操作。出力をPillowで検査し、256×160の原寸とアルファ完全一致、範囲外不変、囲みの14,850画素だけを指定できること、しわ試験画像の121色が出力後も121色として残ることを確認した。ブラシは2,197画素の範囲指定だけが変化し、元画像と別姿勢は不変。

証跡 `test-results/filter-paint/`。試験に使った追加画像/フィルタ/範囲変更は戻して、王の開始例を復元して渡す。
