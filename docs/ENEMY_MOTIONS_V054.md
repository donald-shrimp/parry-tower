# v0.5.4 — 四種の固有モーション＋開発者専用の別入口

## 方針

ユーザー向け本体 \`index.html\` と、開発者用 \`dev.html\` を分離する。本体に開発者ページへのリンク、開発者専用操作パネル、パラメータ入力欄は一切表示しない。

### v0.5.4の敵描画

\`assets/enemy-motions.js\` は戦闘時計を一切持たず、既存 \`enemy()\` が計算した構え \`charge\`、振り抜き \`action\`、接触後 \`recoil\` を使う。

| 敵 | 予備動作と攻撃 |
|---|---|
| 鉄壁の番兵 | 巨大な盾を押し出し、頭上に構えた剣を重く振り下ろす |
| 紅刃の剣士 | 低い構えから交互の二刀を振り出す。奇数・偶数の連撃で主導の手が変わる |
| 残響の詠み手 | 袖で魔法のルーンを描き、伸ばした手から衝撃波を飛ばす |
| 時計仕掛けの兵士 | 回る歯車と伸縮するピストンを構え、直線的に突く |

攻撃先端はすべて敵ローカル座標 \`(motion.reach, -58)\` に着弾時刻で到達する。既存の攻撃命中、BGM、描画のキャラクター配置計算を変更していない。

## 開発者入口

- **本体:** \`https://donald-shrimp.github.io/parry-tower/\`
- **開発用:** \`https://donald-shrimp.github.io/parry-tower/dev.html\` （mainマージ後に公開）
- 現在のDraft PRを手元で試す場合は \`git switch feature/v054-enemy-motion-devtools\` して \`start .\dev.html\`。
- \`dev.html\` から1〜999階の階層指定、特定の通常・精鋭・レア・ボスの強制出現ができる。
- 敵を選択しなければ、指定階の通常出現テーブルによって敵が決まる。
- 強制出現指定はその1戦だけ有効で、その後の階層進行は通常抽選へ戻る。
- 通常プレイヤーが \`index.html?floor=40\` などと指定してもジャンプできない。開発者APIは \`dev.html\` のときにのみ登録される。

**セキュリティ上の注意:** 開発者ページは別URLで非掲載なだけであり、パスワード認証を持たない。公開リポジトリ・GitHub Pagesの仕様上、URLを知れば誰でもアクセス可能。管理用シークレットや課金権限などは置かない。

**セーブ互換:** 開発者ページは既存の\`localStorage\`を読み取り表示するが、魂の欠片・恒久育成・図鑑・入力補正を保存しない。開発者ページのゲーム結果は通常版へ反映されない。

## v0.5.4 初期バランス調整（敵固有ステータス）

敵のステータスは従来の**階層補正→ボス／精鋭／レア補正→敵固有倍率**の順に適用する。元の最低攻撃力13は従来補正の段階に限って適用し、敵固有の0.80倍などを潰さない。

| 敵 | HP倍率 | 攻撃力倍率 | ねらい |
|---|---:|---:|---|
| 影の暗殺者／紅刃の剣士 | ×0.90 | ×0.80 | 手数が多い代わりに一撃が軽い |
| 鉄壁の番兵 | **×1.10** | **×1.00** | 前案の×1.20／×1.15は強すぎるため抑制 |
| 残響の詠み手 | ×1.00 | ×0.90 | トリッキーな譜面に対して被ダメージを控えめに |
| 時計仕掛けの兵士 | ×1.10 | ×0.95 | 機械的な連撃と少し硬めの装甲 |
| ボス4種すべて | **×1.50** | ×1.00 | リズムや仕掛けを長く楽しむ |
| その他の標準敵・レア敵 | ×1.00 | ×1.00 | 旧版からの数値を維持 |

倍率は`assets/encounters.js`の`hpMultiplier`/`atkMultiplier`で個体ごとに定義。小数の丸めは既存のステータス計算のあとに適用する。既存の敵のリズム・BGM・タイミング判定には変更なし。

`dev.html`で任意の階層・個体を選択すると、エリートやボス倍率を含む最終HP・攻撃力、および個体固有倍率を表示する。開発者ページはセーブを書き込まない。

## 回帰チェック

- ジャスト±11ms、通常±31ms、盾先行100ms、共通AudioContext、敵譜面、図鑑・恒久育成の形式を維持
- 4体の攻撃先端が着弾時に盾接触座標に一致
- 4体に固有のシルエット／武器の描画が存在
- 開発者ページで21F・31F・40Fとレア敵・精鋭ボスを呼び出せる
- 通常ページに開発者リンクや開発APIが存在しない
- 開発者ページの戦闘・稽古でも保存値が不変
- GitHub Actionsで\`node --test tests/*.test.js\`

※ 現時点の自動テストはUIシミュレーションと座標検証。端末ごとの映像・音声レイテンシは実機試遊で確認する。
