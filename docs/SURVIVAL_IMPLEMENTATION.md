## 今回の仕様

- 障壁付与を共通化し、既に補充上限を超えている障壁を減らさない。初期障壁・ボス開始加算の既存量は保持。
- 溢命の聖杯（秘宝）：成功パリィの各余剰回復50%を障壁へ。成功1回の変換合計は最大HP5%、補充到達点30%。研磨後65%／6%／40%。割合の上限は切り上げ、余剰からの変換量は切り捨て。通常補充上限も守る。実HP回復だけが血の渇望の火力になる。階層間回復は対象外。
- 結界増幅（RARE、通常上限3）：戦闘中の障壁獲得量と通常補充上限を20/35/50%増加。限界突破Lv4/5は60/70%。初期・ボス開始・非戦闘の付与量と聖杯変換には獲得倍率を掛けない。
- 守護の継承：恒久3段階、60/120/220欠片。新しい戦闘階で最大HP5/8/10%まで障壁を補修。初期・ボス障壁の後に最低量を保証。非戦闘階・第二楽章・停止／中断復帰では再付与しない。ラン開始時に購入値を固定し、旧中断データでは0として扱う。
- 砕けぬ紋章（秘宝）：各戦闘階1回、障壁を超えてHPへ貫通する被害を35%軽減、研磨後50%。氷結→障壁吸収→紋章→蒼銀の鏡→錆びた盾章の順。貫通0では消費しない。減算量は切り捨て。使用済み状態は保存し、停止／第二楽章／中断復帰で復活しない。
- 赤ふんどしの即死規則を優先、無敵練習は新効果も無効。承認済み絵・モーション・拍・入力判定は維持。
