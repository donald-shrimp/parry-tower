# v0.5.2 パリィ手応え改善（試作）

本版はv0.5の判定・敵譜面・BGM同期・スキル/セーブキーを維持した、視聴覚演出の比較検証版です。

- 通常：琥珀色の細い接触火花と短い低音金属打撃、浅い武器反動。
- ジャスト：白銀の火花と金属倍音、40msだけキャラクターのポーズを保持する視覚的ヒットストップ。
- ミス：暗い赤系の小さな火花と鈍い打撃音。攻撃判定は従来のまま。
- 敵反動：スライムの圧縮、騎士・守護者の剣の跳ね、暗殺者の腕の流れ、亡霊の腕と透過表現。
- `strikeResult`の判定後に演出を発生させる。`tap`、`syncAttackClock`、`scheduleScore`、`getPerfectWindow`、`getParryWindow`のロジックは維持。
- 最新本編に合わせて通常パリィ±31ms、ジャスト±11msを維持。

## 稽古場での検証

1. 騎士を選び、ジャストと通常の音・武器反動を比較。
2. 暗殺者、守護者で連撃とヒットストップの重なりを確認。
3. 被弾した場合、反動と音が次の予兆を覆わないことを確認。
4. PCとスマホ両方で描画とタイミングを確認。
