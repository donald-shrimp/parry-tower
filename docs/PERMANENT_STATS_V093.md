# v0.9.3 恒久強化（第1段階）

## 目的
ガードで安全に観察しつつ挑戦回数を重ねた初心者が、恒久的な最大HP・初期障壁を少しずつ伸ばせるようにする。火力は伸ばしすぎない。

## 基礎強化表
| 強化 | 現行上限 | v0.9.3上限 | Lv.1〜5の効果 | Lv.6以降 |
|---|---:|---:|---|---|
| 生命の祝福 | 5 | 12 | +10HP / Lv | +10HP / Lv（最大+120） |
| 剣の研鑽 | 5 | 8 | +3攻撃力 / Lv | +2攻撃力 / Lv（最大+21） |
| 守護の祈り | 5 | 12 | +8障壁 / Lv | +8障壁 / Lv（最大+96） |

共通のLv.1〜5価格は **[8,21,40,65,96]**（累計230）。追加費用：
- HP/障壁：Lv.6〜12 = **[100,130,165,205,250,300,360]**（最終累計1,740）
- 攻撃：Lv.6〜8 = **[150,210,285]**（最終累計875）

## UI
基礎強化のカードに段階進捗バー（role="progressbar"、aria-valuenow/valuemax）、現行ボーナスと次のレベルのボーナスを併記。購入ボタンの価格は新レベルの値に対応。最大到達後はMAXで無効化。従来の特殊強化・スキル装備タブは変更しない。

## データと後方互換
旧 `parryTowerPrototype_v1` の `life` / `attack` / `ward` を引き続き利用。新しい保存キーは不要。これまでのLv.1〜5の購入費用と効果は不変。ロード時に有限数以外や負数は0、旧上限を超える数値は新上限まで正規化し、異常値から巨大なステータスが生成されないようにする。別セーブの `parryTowerPermanent_v1` は変更しない。開発者ページは引き続き保存しない。

## 検証
- 価格と累計費用、Lv.5からの継続購入、最大レベルでの課金ブロック
- UIのボーナス表示、段階数、進捗のアクセシビリティ
- 初期HP185、初期障壁96、攻撃力46の理論値（ラン内スキル未使用）
- 旧セーブの高到達記録、通貨、装備保存と開発者ページ無保存を確認
- 現行の全自動ゲームテストと GitHub Pages 構成確認
