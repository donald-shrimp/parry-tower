# パリィの塔 v1.0.3

タイトル・挑戦終了・一時停止に、工房で調整して確定したレイアウトを採用しました。

- 主操作を単独の上段へ配置し、補助ボタンは下段に中央寄せ。中断データがあるタイトルは「つづきから」が主操作になります。
- スマホ/PC別の文字サイズ・余白・列数・並びを保存済みの確定値へ統一。
- 主操作はピクセルフォント。サブボタンはタイトル/挑戦終了が通常書体、一時停止がピクセルフォントです。
- 絵文字・記号は文字と分けて描画し、ショップの✦などが消える問題を修正。
- PC幅の挑戦終了で、結果文の中央がずれる問題を修正。
- リザルトには使用スキンと挑戦回数を表示。最高到達階・最高コンボはタイトルに残しています。記録の更新・保存は維持します。
- [レイアウト工房](./MENU_LAYOUT_STUDIO.md)を追加。画面別の配置・書体・文字サイズを調整し、保存やJSON入出力、スマホ/PC表示の比較ができます。保存はこのPCの編集データに限り、本番への採用は別途行います。

既存ボタンの操作、敗北直後の入力ロック、中断・再開、プレイヤーの保存形式は維持しています。戦闘の数値やタイミングは変更していません。
