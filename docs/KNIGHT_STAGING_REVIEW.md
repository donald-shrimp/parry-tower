## 分かったこと

1. PCの現在版は、見た目の背丈がmainの約1.5～1.6倍。さらにマントや横へ構えた剣による幅が広く、両者の間の空間が減っている。縮尺をPNG全体の外接矩形で合わせると、武器・布の形が基準を変えてしまう。兜～足の背丈を基準にする。
2. 現在の騎士は layout で restX=contactX、stageX=contactX。予備動作+8、接触-6ローカル単位だけ滑るため、接触の近くで戦う状態が続く。
3. mainの敵は画面幅73%付近で待機し、予備動作で stageX=contactBodyX+m.stage*scale へ、攻撃で接触位置へ向かう。溜め位置から接触までの根元の移動はPCで約187px、スマホで約94px。現在は約26px、約9px。今の腕・剣だけでなく全身の接近量を戻す効果が大きい。
4. スマホ用の舞台を以前の改善で448pxから304pxへ縮めていた。同じ画面幅でも空間の見え方が変わる。PCへ合わせて一律に現在の6割へ縮めると、スマホで小さすぎる可能性がある。
5. 全フレーム・全武器を画面内へ収めるレイアウトとテストが、今回の好みと衝突。mainは固定の縮尺・位置を使い、動きに応じた一時的な見切れを許す。
6. mainにはパリィ後の全身の押し戻し（騎士24ローカル単位）と回転がある。現在は主に胴の小さい傾きで、根元位置へ反動が入っていない。ここも敵を弾いた感触を弱めている。

## 次に試す一回分の範囲

- キャラ背丈と定位置：main相当を出発点にする。PCは現在の6～7割程度を最初の目安とし、スマホは元の舞台高を戻して別に判断する。主人公は幅28%、敵待機は73%付近を基準に、原画の実際の重心と横幅で微調整。
- 接近モーション：今の自然な待機・足の構え・肩肘剣の連動を残し、敵の全身を離れた待機→後退する予備→素早い接近→接触へ移す。腕で長い距離を埋めず、剣先は実際の盾へ既存時刻に合わせる。
- 見切れ方：待機では顔・主要な胴、接触では盾と剣の打点を読める状態にする。攻撃中の剣先・後方の布・後ろ側の一部は画面外を許す。全外接矩形の収まりを義務化しない。
- 当たりと復帰：既存の短い接触保持を活かし、パリィで敵の根元が押し戻されてから間合いへ戻るようにする。脚をジタバタさせない。必要なら一枚につないだ布だけ遅れて追従させるが、位置と接近を先に確認する。
- 変更しない基準：原画、左右の持ち手・順序、ゲーム時計、判定、音声、ダメージ、保存。テストは厳しい全画面内チェックを、新しい「重要部位・接触点は読み取れる」条件へ更新する。
