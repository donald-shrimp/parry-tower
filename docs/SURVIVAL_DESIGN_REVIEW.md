# 回復・障壁の後半評価と追加要素の企画案

2026-11-01。初回調査対象 c8698cc（v0.9.7系のローカル候補）。以下は初回提案時の評価と比較結果の記録。

追記：ユーザーが「バグを直して4つとも実装」を採用。[SURVIVAL_IMPLEMENTATION](./SURVIVAL_IMPLEMENTATION.md) の仕様でローカル実装した。以下の優先順位・未採用表現は提案時点のもの。現在の `scripts/survival-analysis.js` は実装済みコードで個別／全部入りを比較する。元の提案時の試算はこの文書と `test-results/survival-analysis/report.json` に残す。

## 結論

「後半ほど回復や盾の意味が薄れる」という感触は、特に固定量の効果と、一撃死に近い状況からの復帰について裏付けがある。ただし吸血＋狂戦士、育った魔法障壁、氷結は後半でも有効であり、一律強化には慎重さが必要。

最初の候補は **余剰回復を障壁へ変えるレリック「溢命の聖杯」**。満タン中の回復を次の失敗への備えにでき、既存の回復ビルドに新しい役割が生まれる。次点は **スキル「結界増幅」**。障壁の容量だけでなく補充量も育てる。恒久強化と盾破壊時の救済は第2候補にとどめ、最初から全部を重ねない。

追加前に、障壁を補充すると保有量が減る既存挙動を修正する価値が高い。

JUST数は障壁0から単純に補充する場合。敵を倒す一撃では魔法障壁処理まで到達しない場合もある。比較のスキルをこの階までに入手できる保証はない。

### 1. 回復が追いつく前に死ぬ

80階でHP275＋障壁55から通常被弾するとHP5。仮定ビルドの直後の通常パリィで吸血が60回復しHP65になるが、次のガード98で死亡する。この順序を実戦処理で再現した。回復自体が働いていても、次の失敗を許容するHPへ戻るまでに間がある。

再生力は最大HPの20%なので、この条件なら55回復。量はHPに追従するが、発動は勝利後であり、ボス戦中の立て直しには使えない。戦利品の20%回復・安息の35%回復も階層間の補給。

### 2. 固定量の回復・障壁が相対的に小さくなる

- 巡礼者の鐘：4パリィでHP4、研磨後6。80階のガード98をこれだけで補うには100／68パリィ必要。
- 血盟の杯：各階最初のHP被弾後にHP8／12。80階のガード被害の約8／12%。その被弾で死亡すると回復まで届かない。
- 魔法障壁Lv4：JUSTで15。ガード98に対して約15%。一方、Lv10なら33、3JUSTで99となり、特化すれば意味は残る。
- 蒼銀の鏡：HP被害軽減20%／30%でも上限8／12がある。障壁なしでガード98を受けると軽減は8／12で頭打ち。
- 安息の瞑想・商人の護符：障壁20は10階ではガード1回分以上、80階では約20%。容量を増やすだけでは補充量の不足を解決しない。

### 3. 満タン時の回復が備えにならない

`heal()` は最大HPで切り捨てる。吸血・血の渇望・鐘などの余剰回復は保存されない。血の渇望も実回復だけを次の火力へ変えるので、HP満タンでは回復由来の蓄積は0。満タンでうまくパリィを続ける時間を、後の耐久へ還元できる余地がある。

### 4. 既存の強い組み合わせもある

- 吸血は与ダメージ比例。単独の回復上限は最大HP25%で、HP275なら69だが、狂戦士との血の律動はコンボごとに吸血率・回復上限が上がる。50コンボなら上限207。実際に十分なダメージを与えればこの回復が発生することを確認した。
- 氷結Lv6は4パリィで次の一撃を75%軽減。325被害を82にでき、HP275・障壁0から193残る。既に割合軽減による後半向けの防御が存在する。
- 通常上限まで生命の器を育てると最大HP335、突破込みなら365。魔法障壁の上限も通常300／突破込み340。上の表は最大完成ビルドではない。

## 補充で障壁が減る既存挙動

初期障壁96＋ボス開始55＝151を持てる一方、補充側は `min(100 + 魔法障壁Lv×20, 現在量 + 獲得量)`。上限を超えている場合、足す操作で減ってしまう。

- 障壁151、魔法障壁Lv1でJUST → 本来+6の場面で **120へ低下**。
- 障壁151、魔法障壁なしで障壁+20 → **100へ低下**。

両方を実処理で再現した。新効果を足す前に、既存量を削らず「上限以上なら追加0」とする共通の障壁付与処理にそろえる。ボス開始の加算と通常補充の上限をどう扱うかは明文化する。既存の開始障壁まで黙って削る変更はしない。

## 企画A：レリック「溢命の聖杯」— 第1候補

**秘宝。成功パリィに伴う余剰回復の50%を障壁へ変える。**

- 対象：吸血、血の渇望、巡礼者の鐘、血盟の杯による成功パリィ中の回復。回復が先、その余りを変換。
- 1成功パリィで変換できる量は合計で最大HPの5%（切り上げ）。回復イベントごとに上限をリセットしない。
- この効果で補充できる障壁は最大HPの30%（切り上げ）まで。他の効果でそれ以上の盾を持っている場合は減らさず追加0。
- 変換量は各回復の余剰×50%を切り捨て。HP275なら1パリィ最大14、補充到達点83。
- 階層クリア時の再生、戦利品回復、安息、最大HP増加、復活は初期案の対象外。特に再生力だけで毎階自動的に盾を備蓄する効果にはしない。
- 盾の獲得を回復として再処理しない。血の渇望の蓄積には従来どおり実HP回復だけを使う。
- 撃破パリィの回復も対象。撃破後の再生を巻き込まないよう、処理の発生元で区別する。
- レリック交換で変換効果を失っても、既に得た通常障壁は残す。

研磨候補は変換率65%、1パリィ上限6%、到達点40%。**研磨値は未試算**。初回試遊は未研磨版で行う。

楽しさ：回復を引いたときに「満タンだから無駄」が減る。鐘などの小回復にも、失敗前の備えという役割が生まれる。高コンボ吸血による過剰な蓄積は、1パリィ上限と補充到達点で抑える。

制約：回復手段との組み合わせが必要。吸血が強い構成ほど得をするため、実際にレリック3枠の1つを使う価値と、回復を引けないランでの選びにくさを確認する。

## 企画B：スキル「結界増幅」— 第2候補

**RARE、最大Lv3。戦闘中の障壁獲得量と通常補充上限を20／35／50%増やす。**

- 魔法障壁、不滅の盾、欠けた歯車、静謐の水晶、王の戦旗が対象。1回の付与量を倍率適用後に切り上げる。
- 初期障壁・ボス開始加算・安息・商人の付与量は初期案では対象外。戦闘中の継続的な補充を強化する。
- 通常補充上限は `(100 + 魔法障壁Lv×20) × (1 + 増幅率)` を切り上げ。既に上限以上の盾は減らさない。
- Lv3＋魔法障壁Lv4ならJUST15→23、上限180→270。ガード98を補うのに7→5JUST。
- Lv3＋魔法障壁Lv10なら33→50、上限300→450。育てきった盾ビルドが完成形として見える。
- 聖杯による変換は対象外とし、変換側の1パリィ上限・到達点も増やさない。最初から相乗効果を複雑にしない。

楽しさ：障壁を生む既存スキル・レリックがビルドの軸になる。容量だけを増やして空のままになる問題も避ける。

制約：単独では盾を生成しないため、取得画面で対象効果を示す必要がある。新スキルで抽選プールを広げるコストもある。試遊で役割が曖昧なら、新スキル追加ではなく既存魔法障壁の後半成長の調整を比較する。

## 企画C：恒久強化「守護の継承」— 保留候補

新しい戦闘階へ入るとき、障壁が最大HPの5／8／10%未満ならその量まで補修する。加算ではなく最低量の保証。仮の費用60／120／220欠片、**費用と効果は未試算**。

HP275ならLv3で最低28。初期障壁96やボス障壁55を持つときは効果なし。初期障壁を使い切った道中で役割がある。非戦闘階・第二楽章・停止再開・中断ロードでは発動させず、階移動を反復して蓄積できないようにする。

長所は、守護の祈りが尽きた後も各戦闘に小さな盾を持てること。短所は全ビルドへの一律救済であり、ボス戦中の復帰には直接効かないこと。A/Bを試しても道中が苦しい場合に検討する。

## 企画D：レリック「砕けぬ紋章」— 初回導入は見送り

各階1回、障壁が割れる攻撃でHPへ貫通する被害を35%軽減。最初の被弾への橋渡しを目的とする。試算は氷結なしの条件。研磨・氷結との処理順は未確定。

80階の例ではHP5残りがHP99残りになり、次のガード98に1HPで耐えられる。ただし、下記の長いボス戦比較では最終勝利の改善が小さかった。既存の氷結とも役割が近いため、まずA/Bを優先する。

## 候補効果の比較試算

新規 `scripts/survival-analysis.js` は既存スモークテストのVMを利用し、**実際の戦闘関数**を呼ぶ。候補効果だけをメモリ上で差し替え、本編ファイル・プレイヤーのセーブは変更しない。

- 各条件400試行。候補間は同一seed・同一の操作結果列で比較。
- パリィ中心：JUST30%／通常PARRY57%／GUARD10%／MISS3%。
- ガード多用：JUST10%／通常PARRY45%／GUARD40%／MISS5%。
- 各階のスキルは既存の仮定値、恒久最大・通常スキン・満タン・開始障壁55。道中、実入力タイミング、BGM時間、スキル抽選、追加効果の取得費用や選択を失う機会、既存レリックの組み合わせは再現しない。
- 比較は「同じビルドに候補を追加できた場合」。実際の強化報酬・レリック枠を使った場合の純増効果とは異なる。新効果の使える最大量まで事前蓄積せず、同じ開始障壁55から始める。
- 結界増幅はLv3を比較。聖杯は未研磨、砕けぬ紋章は35%・1回。組み合わせ同時導入は未試算。

### 無限階層について

終刻の王系の攻撃力は80階325、100階412、160階843、240階2190。一方で通常スキンの最大HPは突破込み365、既存の通常補充上限は340。160階ではこの合計705でも無軽減の通常被弾を耐えられない。

今回のA/Bは有限量の備え・補充を改善する案であり、無限階層でいつまでもMISSを許す仕組みにはならない。ガードの被害は最大HP40%で頭打ちだが、通常被弾にはその上限がない。無限階層全体の失敗許容を変えるなら、既存の氷結・復活を含めた別の難易度設計として扱う。

## 推奨する次の実装・試遊範囲

1. まず「補充で盾が減る」挙動だけを修正して回帰確認する。
2. Dev限定でAの未研磨版、BのLv1〜3を個別に比較できる候補を作る。本番への追加・公開は採用判断後。
3. 40／60／80階で、鐘中心・吸血のみ・吸血＋狂戦士・盾特化を比較。恒久無強化／中程度／最大、ひよこ、死神の盟約、研磨も含める。
4. Aでは1回の成功に複数回復がある場合の合算上限、撃破時の回復と再生の区別、保存復帰、交換を検証。Bでは全付与元と上限超過保持、Aとの重複を検証。赤ふんどしの即死規則は優先する。
5. プレイで「回復を引く価値が出たか」「立て直し中もパリィが必要か」「火力を捨てて選ぶ魅力があるか」を確認する。無限防御や死亡までの時間だけ増える状況も確認する。

初回はAを推す。Bも有力だが、抽選プールを広げる前に、既存魔法障壁の調整で同じ目的を達成できるかを比較したい。C/Dと固定値レリック全体の強化は、初回結果を見てから判断する。
