# v0.7.0 — 塔の岐路（Draft PR #16）

## 目的

10階ごとのエリアで固定の敵構成・ボス・レリック報酬は残し、**4Fと8Fの通常戦闘だけ**を三択の分岐階層へ置き換える。
非戦闘ルートは安全と引換えに通常のスキル報酬を失う。血闘ルートは強い精鋭と戦う代わりにコンボ維持・通常報酬・塔貨増収を狙える。

### 階層

- **各エリアの4F（4,14,24,34…）**：🔥安息の間、🛒行商人の隠れ処、⚔️血闘の間。
- **各エリアの8F（8,18,28,38…）**：🔥安息の間、🔮奇遇の間、⚔️血闘の間。
- 各エリアの**5F/10Fの固定ボス**、**9Fの固定精鋭**、**3Fの初回レリック報酬**は従来どおり。
- 分岐に入るには前階の通常/レリック報酬選択を済ませる必要がある。分岐の決定・商人・イベント中は敵の攻撃やBGMクロックは進まない。
- ルートの選択は戻せない。安息・行商人・奇遇での効果確定後は「次の階へ進む」を押して進む（繰り返し獲得不可）。

## 4つの部屋

| 行き先 | 戦闘 | 報酬/選択肢 | コンボ |
| --- | --- | --- | --- |
| 🔥 安息の間 | なし | HP最大値の**35%**を回復、あるいは障壁+20と引き直し+1 | 入室時にリセット |
| 🛒 行商人の隠れ処 | なし | 「塔貨」で訪問ごとに商品**1つ**購入、または買わずに退出 | 入室時にリセット |
| ⚔️ 血闘の間 | 精鋭戦 | 敵のHP約1.3倍・攻撃力約1.15倍、通常スキル報酬と塔貨14枚、通常の**精鋭20%**レリック抽選 | 維持可能 |
| 🔮 奇遇の間 | なし | 4種類のイベントから1種類を抽選して選択肢を提示 | 入室時にリセット |

- 魔法障壁の現在の上限（`100+20×魔法障壁Lv`）は、イベントや商人の獲得障壁にも適用する。
- 非戦闘ルートは**コンボ・連続JUST数**を0にするが、奥義チャージ、取得済みスキル・レリック、雷撃などの蓄積状態は維持。
- 固定ボスの戦闘、音楽テンポ、JUST/パリィ判定は変更しない。

## 塔貨（ラン限定通貨）

魂の欠片と完全に分離し、所持量・獲得総額をラン中のメモリだけに保持。死亡/帰還/新しいランではリセット。既存の `parryTowerPrototype_v1` と `parryTowerPermanent_v1` の形式は一切変更しない。

| 討伐対象 | 塔貨 |
| --- | ---: |
| 通常敵 | 6 |
| 精鋭・レア敵 | 12 |
| ボス | 10 |
| 血闘の間の精鋭 | 14 |

### 行商人の商品

| 商品 | 価格 | 効果 |
| --- | ---: | --- |
| ↻ 運命の札 | 12 | スキルの引き直し+1 |
| 🛡️ 結界の護符 | 16 | 障壁+20 |
| 📜 秘伝の巻物 | 26 | 通常抽選ルールからスキルを**一つ選ぶ**。封印済みは除外し、選択眼で4択に対応 |
| 🏺 封印された遺物箱 | 42 | **風化60%・秘宝40%・神話0%**で遺物3択。3枠が埋まれば持ち替えか見送り |

商品が購入できない（不足通貨、スキルの最大レベル到達、遺物候補枯渇など）場合はボタンを無効化する。商品は1訪問につき1つだけ購入可能。購入した遺物を見送っても返金はしない。

## 奇遇の間

奇遇の間へ入るたびに、独立した4イベントから1種類を抽選。**イベント結果が確定するまで再抽選不可**。結果表示から次階へ進むと通常の階層報酬は与えない。

| イベント | 選択A | 選択B |
| --- | --- | --- |
| 🩸 血の祭壇 | 最大HPの12%（端数切上げ）を支払いスキル報酬から1つ選択。HPが1以下になるなら不可 | 障壁+12 |
| 🪞 忘却の鏡 | 現在所持するレリックを1つ指定し、別の風化・秘宝レリック3択から交換。外した遺物は同じランで再取得不可 | 塔貨+12 |
| 🎒 旅人の遺品 | 塔貨+18 | 引き直し+1・障壁+10 |
| 📦 封じられた宝箱 | 40%で風化・秘宝レリック3択、60%で最大HPの20%分のダメージ（端数切上げ）。ダメージは現在HP-1を上限とし、**HP1で必ず生存** | 開けずに塔貨+10 |

- 祭壇・宝箱のHP減少は**イベント支払い/罠**扱いで、攻撃を受けたことにはしない。つまり不屈・血盟の杯・反射・氷鏡・止まった秒針などは発動しない。
- HP満タンに戻すもの以外の回復は実際の不足HPまで。回復がその後の血の渇望へ誤って加算されることもない。
- 鏡の遺物交換は、新しい遺物を確定するまでは元の遺物が保持される。選択画面の見送りで鏡に戻り、塔貨+12の代替選択ができる。
- 遺物のショップ/宝箱/鏡の抽選に、現行 `ParryRelics.offer('special')` を再利用し、既所持・同ラン破棄済みは出現させない。
