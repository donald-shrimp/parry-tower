通常のローカル実行は全組み合わせを検証する。CIでは `index.html`、`dev.html`、`credits.html`、画面用CSS、文書だけのPRで代表ケースを使う。ゲームや素材、テスト自体を含む変更、mainへのpush、手動実行は全組み合わせを検証する。公開前は候補ブランチで全組み合わせを通す。画面・文書のみのPRを公開する場合は、候補ブランチで Actions の Static checks を手動実行する。

同じローカル環境で、描画4件とテンポ1件をまとめて実行すると72.1秒から14.0秒になった。PR全体の短縮時間はCIで別途計測する。短縮プロファイルで精鋭の補正を+6から+7に変えるとBPMのテストが、セーブ置き換えの確認を外すと中断データのテストが失敗することを一時的な差し替えで確認した。

次の棚卸しでは未採点の項目を扱う。上位20件のうち、独立した回帰を守っているものは維持する。
