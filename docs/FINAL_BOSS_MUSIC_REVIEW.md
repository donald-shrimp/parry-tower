# 75階・80階の曲試作

ユーザー指定の「75階は行進、80階は今のBPMのまま本気を出す」を、同じ主題の異なる編成で表現する。既存のWeb Audio方式で16小節ループを作り、DevのBGM試聴室へ明示選択の候補として追加した。

## 試聴

<http://127.0.0.1:8006/dev.html?music=king-march>

リンクで試聴室が開く。音声の自動再生はせず、上段の3ボタンで切り替える。停止・従来8曲との比較・この曲での無敵練習も利用できる。

| 候補 | 内容 | 基準BPM |
| --- | --- | --- |
| `king-march` 王の行進 | 75階。低い金管が主題を断片的に提示。太鼓・行進スネア・低いオルガン | 136 |
| `king-awakening` 終王の覚醒 | 80階。完成した主題、重奏金管、刻む弦と厚い和音 | 142 |
| `king-finale` 終王の覚醒 — 第二楽章 | 80階。高音の金管で新しい旋律、1小節ごとの和声、開始4拍と同じ太鼓、中盤の低い旋律から最終全奏へ | 142 |

### 第二楽章の改訂（revision 2）

第一楽章はユーザーより高評価。第二楽章は差が小さいとのフィードバックを受け、16分弦の追加だけだった構成から、4つのフレーズを持つ新しい旋律・和声・低音リズムへ改訂した。BPMと16小節の長さを維持し、75階と第一楽章の全128ステップは改訂前のハッシュと一致する。

冒頭は高い金管と4拍の太鼓、次の句では王の主題を短く圧縮する。9〜10小節目で低い旋律と疎らな太鼓へ落とし、最後の4小節で金管のオクターブ重奏と合唱を戻す。太鼓は `scoreFinalKick` と同じ220→92Hzのtriangle、135→55Hzのsine、950Hzの打撃ノイズ、380Hzの低音ノイズを、曲中に合う音量で合成する。

実戦の第二楽章では4拍カウントを譜面位置から差し引き、導入後に曲の冒頭から入る。先読み予約がカウント終了後の音を消さないようにし、導入中は元の4打だけを維持する。攻撃の時計・最初の攻撃までの4拍・既存8曲の処理は変更しない。

直接試聴：<http://127.0.0.1:8006/dev.html?music=king-finale&revision=2>。新しい音声は `test-results/final-boss-music/revision2/king-finale.wav` と `royal-suite.wav`。旧第二楽章は同フォルダの隣の `revision1/king-finale.wav` に残す。

80階の第一楽章を指定して練習すると、既存の第二楽章遷移後に編成も変わる。「第二楽章」単独候補は音楽をすぐ比較するための編曲指定であり、練習開始時に敵のHPや攻撃譜面を第二楽章へ変更する操作ではない。

試聴は基準BPM。練習は既存の遭遇計算を使い、時空スキン・緩慢を選んだ場合はその補正が加わる。75階は通常の王、80階は精鋭の王を指定する。

## 実装範囲

- `assets/final-boss-music.js` が純粋な譜面生成と音色の描画を提供。Devだけが読み込み、既存の時計・BGMバス・音量・停止処理を使う。
- 旋律はDマイナーを中心に、D–A–Bb–C#–Dの主題を共有する。デチューン金管、弦、オルガン、対旋律、大太鼓を既存のシンセ方式で合成。
- 本編とDevの通常開始の自動選曲は従来どおり。既存8曲とBPM計算式、4拍の第二楽章カウント、攻撃譜面、保存形式を保持。
- 曲名の表示に必要な字形を公式原フォントから追加し、従来の字形・権利表記を保持。フォントのキャッシュ識別子を6へ更新。
- ローカル試作。ビルドはv0.9.6のまま。採用・本番公開は今回の範囲に含まない。

## 音声書き出し

`scripts/render-final-boss-music.js` は同じ譜面・音色関数を使い、44.1kHz stereo / 16bit WAVを出力する。追加依存はゲームには含めず、無視対象の検証用フォルダへ置く。

```powershell
npm install --prefix test-results/final-boss-music/runtime --no-package-lock --no-save --ignore-scripts web-audio-engine@0.13.4
node scripts/render-final-boss-music.js
```

`test-results/final-boss-music/audio/` に各曲約28〜29秒と、75階→80階前半→第二楽章の約83秒の `royal-suite.wav` を生成。音声サンプルが有限であること、クリップがないことを検査し、`render-metrics.json` へ記録する。戦闘SEとプレイヤーの音量補正は含まない。

改訂後は譜面/音色8件とゲーム統合9件、フォント2件成功。カウント終了100ms前の先読みから、正しい境界時刻に新曲の第1小節と太鼓を予約すること、カウント中へ音が漏れないこと、停止/一時停止/時計復帰を検証した。WAV書き出しのpeakは約0.1285でクリップなし。全体454件の回帰は初回作曲時の結果で、今回の改訂では上記関連検証を実施した。

改訂した第二楽章の迫力・好み、実プレイで準備音を聴き取れるかはユーザーの試聴対象。検証結果と次の作業はHANDOFFを参照。
