# v0.5.6 — 恒久強化・初期装備

## 目的とUI
- タイトルと死亡画面には「✦ 恒久強化・装備」入口だけを置き、長いショップを撤去。
- 専用パネル内を「装備 / スキル解放 / 基礎強化 / 特殊強化」の4タブに分割。
- 死亡画面からの移動は既存の誤タップ防止500msを尊重。戻ると元の画面に戻る。

## 初期スキル
- スロットⅠ：20 ✧、スロットⅡ：65 ✧。2枠まで。
- 装備できるスキルは別途1種類ずつ永久購入。購入していないものは装備不可。
- 装備の変更・解除は無料。同じスキルの二重装備は不可。
- 装備スキルはLv.1で出撃し、通常の階層報酬で同種スキルを引いたらLv.2以上にできる。
- 未購入スキルもラン中の通常のスキル抽選からは除外しない。
- 稽古場は従来どおり初期スキルなし。

### 将来のスキル追加に対する互換性
唯一のスキル一覧 `SKILLS`（`assets/game.js`）からショップを動的生成する。追加したスキルを別の固定配列へ再登録する必要はない。

`assets/progression.js` の `skillPrice(skill)` は次の優先順位で費用を決める：
1. スキル定義の `startCost`（価格の明示的な個別指定）
2. 既存スキルの価格例外リスト
3. レアリティ別初期値 common=25 / rare=90 / epic=300 ✧
4. その他の未知レアリティは35 ✧

新スキルはユニークで変更しない `id` を使うこと（名称変更は自由）。購入済みIDをセーブするので、改名後も装備を維持できる。削除・一時停止したスキルの購入履歴は残し、再実装された場合に復帰できる。装備時は必ず現在のスキル一覧に存在することを検査する。

### 全18種類の初期スキル解放価格
- COMMON: 剛剣15、落雷25、吸血25、魔法障壁25、一点集中20、心眼25、静かな呼吸20、灼熱20、生命の器30
- RARE: 背水60、反射70、処刑人75、残響90、狂戦士90、共鳴波90、緩慢の呪い120
- EPIC: 奥義紋300、双撃300

## 強化
既存の生命の祝福/剣の研鑽/守護の祈りは価格・上限・効果を変更しない。

| 新強化 | 費用 ✧ | 累計効果 |
|---|---|---|
| 再生力 Lv.1〜3 | 12/24/45 | 階層クリア時 HP 5/10/15%回復 |
| 守護の備え Lv.1〜3 | 15/30/55 | ボス戦突入時 障壁 +5/+10/+15 |
| 魂の共鳴 Lv.1〜3 | 30/60/100 | 獲得魂の欠片 +5/10/15%（切り上げ） |
| 出撃準備 | 25 | ラン開始時の引き直し +1 |
| 選択眼 | 80 | 階層報酬4択 |
| 不死鳥の加護 | 150 | 1ラン1回、致死ダメージを受けると最大HP30%で復活 |

初期スキル装備の生命の器は出撃時最大HPにも反映。復活でもAudioContextの時計、譜面、パリィ判定は変更しない。死亡後500msの入力保護も維持。

## データ互換性
- 既存 `parryTowerPrototype_v1`（魂の欠片・既存3種の強化）を読み書きし、移行しない。
- 新しい `parryTowerPermanent_v1` にバージョン付きのスロット数・解放済みスキルID・装備ID・追加強化を保存。
- 初回プレイは新データの初期値から開始。破損した状態や未解放の装備、重複装備は正規化する。
- `dev.html` は両データを読み取れるが、新旧どちらのセーブ領域にも書き込まない。
