# v1.0.0 に向けた先行実装・演出レビュー

## 承認された範囲

右上に設定（BGM/効果音各0–200%、現行音量=100%、揺れ/フラッシュ切替）。タイトルのスキン名を非表示。おすすめタイミング調整を設定内に置く。Firebaseは使わずローカル中断保存を実装。タイトルに短い任意チュートリアルを追加し、1Fの敵撃破→通常の戦利品→2Fへつなぐ。

エンディングは本編へ接続せず、独立した確認画面で花火増加→カメラが引く→塔爆発→生還→踏破の演出を調整する。再生/停止/速度/シーク/演出量の変更を可能にする。正式版v1.0.0の採否はユーザーの演出レビュー後。

## 設計と工程

1. 設定・補正の純粋データ処理とUIを追加。補正の測定も既存AudioContextを使用し、候補は試してから保存。既存の手動補正を勝手に変更しない。
2. バージョン付きの中断スナップショットを追加。選択済みの敵/候補を保存し、再開で抽選や報酬付与を繰り返さない。実時間・音声ノード・画像ロード状態は復元しない。Dev/稽古場は中断セーブに書かない。死亡で削除、新規開始時には既存の中断を置き換える確認を出す。
3. 1Fチュートリアルを実装。ガード→パリィ→ジャスト紹介、ジャスト必須にはしない。失敗の即死/HP減少を抑え、終了後は通常ルールへ戻す。既存の通常プレイと採用済み判定を保持する。
4. 既存主人公の表示を使う独立エンディング確認画面を作る。ゲーム/恒久保存と分離する。
5. 設定保存/実ゲイン、補正の外れ値・取消・時計、中断の全モード/候補/購入/死亡/再開、チュートリアル移行、演出シークと無保存をテスト。既存全回帰・画像・フォントと実GUIを検証し、確認版を届ける。

確認版の識別子はv0.9.5-preview。エンディングは未採用のため、v1.0.0公開は今回行わない。
