# 採用済み立ち絵・モーション

2026-10-20、ユーザーが全体の立ち絵/動作、終刻の王のフィルタ手塗り、「一番上」の細かめドット加工、本編導入とマージを明示了承。

## 本編の表示

`index.html` と `dev.html` はURL指定なしで細かめ（原画6pxを1ブロック、キャラ共通64色）の立ち絵を使う。主人公＋敵26種をカバーし、構え/打ち込み/補修布の座標と既存の切り抜き、手動ポーズ、回転軌道、中割り/残像/踏み込みを保持する。白い反撃衝撃波は0.2秒、通常パリィとジャストの大きさ、精鋭の赤黒いオーラ、レアのきらめきも維持。

`character-style.js` が画像パスだけを解決し、既存puppetで描く。色違い11体は了承済みの事前加工画像を使い、全体色相フィルタを重ねない。炉心の管理者は同一の基本素材と従来の色相フィルタを維持する。共有原画のモーションは同じまま、画像/部品キャッシュを敵の配色IDで分ける。敵キャッシュは直近4種類、主人公と基本騎士/色違い騎士は個別に保持し、出現しない全キャラを起動時に展開しない。タイトルでは `ParryKnightPuppet.preloadSources()` が採用画像全件を重複排除し、低優先度で3並列先読みする。各画像はブラウザのリソースキャッシュを利用し、アプリ側に全員の展開済みパーツを保持しない。戦闘時の対象部品が未準備なら読み込み表示を挟み、準備後にBGM/攻撃時計を開始する。描画中の画素加工はない。

`studio-project.json` の updatedAt **1792426370286** を変更せず、`character-art-defaults.js` へ同梱する。初回に確定済み動作を持ち、HTTPでは正本JSONも読み込む。より新しい手動適用データを保持し、古いブラウザ保存が確定版へ戻すことを防ぐ。セーブ、音声、判定、ゲーム状態の形式は変更しない。キャッシュ識別子は `v0.9.3-6`。

## 終刻の王

`assets/character-art/approved/endking/` の `project.json` が元画像・フィルタ・両姿勢の適用範囲を含む正本。`ready.png` / `contact.png` は了承済みの工房書出し。冠は黒鉄、腰布/外套の裾は紫、胸飾り/鍔は金、赤い目は維持する。再加工で以前の自動領域へ戻さない。配色manifestには書出しPNGと編集JSONのSHAも記録する。工房の開始例もこの範囲から再編集できる。

## 再生成

Node.js、Python、Pillow、NumPyが必要。

```powershell
node scripts/build-art-defaults.js
python scripts/build-pixel-art.py
python scripts/build-palette-art.py
python scripts/build-filter-paint-starter.py
node --test tests/*.test.js
python -m unittest discover -s tests -p 'test_*art.py'
```

元原画を上書きしない。標準/レトロも比較ページ用に残し、本編は細かめのみ読み込む。原画の工房/比較レンダラーは独立し、ゲームの既定表示へ変更を及ぼさない。`?art=illustrated` は本編の採用素材を使い、他の明示した旧試作URLは引き続き利用できる。

## 検証

Nodeの全キャラ/戦闘/保存互換、画像ハッシュ/寸法/共通パレット/整数格子、最新王の素材、配色の二重掛けと連続切替、確定動作と新しい編集の優先順位を検証する。実ブラウザでも全26敵＋配色の再訪7例、900×550と360×640の7時点で計462描画成功、警告/エラーなし。デスクトップの描画呼出し実測は中央値0.10ms、95%点0.50ms、最大5.30ms（初期素材展開を含まず、端末全体FPSやスマホ実機の保証ではない）。終刻の王は75Fの実背景でも確認。

証跡は `test-results/adopted-art/`、テスト結果は `test-results/integration-*.txt`。実スマホの操作感と実音声に合わせたタイミングはユーザー実機で確認する。
