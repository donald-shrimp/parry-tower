# v0.5.2 B — 派手な爽快感重視（試遊比較版）

- `main` のBGM・譜面・パリィ判定・保存キーは変更なし。
- A版の物理的な敵リアクションを残したうえで、B版は青白い閃光、二重の衝撃波、斜めの閃光線と光粒を強調。
- ジャストの音はBGMと同じAudioContextで短い3音の上昇フレーズを再生。通常は短い2音。
- 連続ジャストで光のエネルギーだけが少し増す（火力・発動確率・コンボ判定は不変）。
- 次の攻撃の風切り音や予備動作が始まる前にエフェクトが薄れる。画面全体の白飛びは短時間に制限。
- 40msヒットストップは表示上の姿勢停止のみ。拍・入力・敵の命中時刻は止めない。

比較方法：稽古場の騎士・暗殺者・守護者で、A版とB版のジャスト／通常パリィを比較する。少し暗い画面で遊んだときの視認性と連撃時の予兆の見え方を重点確認。
