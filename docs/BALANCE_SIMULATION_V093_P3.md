# v0.9.3 第3段階 — バランス検証の方法・評価ポイント

## 目的
第1・2段階の恒久強化拡張後、10/20/40/60/80階で攻撃力成長と救済効果の整合性を再検証する。結果の再現性を担保するため `scripts/balance-simulation.js` にモデルを実装し、GitHub Actionsで同じ数字を算出する。

## 実際のロジックと比較する部分
- ボスの固有データ、階層別HP・攻撃力：`assets/encounters.js` の生成関数を直接使用。
- 初期HP・攻撃・障壁、ボス開始時障壁、再生率、魂増加：`assets/progression.js` のAPIを直接使用。
- ガードは敵攻撃の30%か最大HPの40%の小さい方を切り上げ、障壁が先に吸収する。コンボは20%（最低5）減少。パリィは剛剣・狂戦士・落雷・残響・吸血・奥義、ジャスト時の魔法障壁を計算して近似。
- 全プロフィールで同じ仮定のラン内スキル構成を採用し、恒久強化の影響だけを比較する。

## 前提の明示
プロフィール：
- **無強化**：基礎強化・追加恒久強化の購入なし。
- **中程度**：生命Lv6、剣Lv5、障壁Lv6、再生力Lv3、守護の備えLv3、魂の共鳴Lv3。
- **最大強化**：生命Lv12、剣Lv8、障壁Lv12、再生力Lv5、守護の備えLv6、魂の共鳴Lv5。

スキルは各階層で固定した**説明用の仮定**。10階＝剛剣1・吸血1、20階＝剛剣2・生命の器1・吸血1・魔法障壁1、40階＝剛剣4・生命の器2・吸血2・魔法障壁2・狂戦士1・落雷1・残響1、60階＝剛剣6・生命の器4・吸血3・魔法障壁3・狂戦士2・落雷2・残響2、80階＝剛剣8・生命の器6・吸血4・魔法障壁4・狂戦士3・落雷4・残響3。これを引ける保証はない。

開始HPは満タン・コンボ0で比較。**保守条件**は初期障壁を道中で使い切り、ボス開始時の「守護の備え」だけある場合。**楽観条件**では初期障壁も温存し、ボス障壁に加算する。実ランでは中間状態があり得る。

操作成功率はプレイヤーデータから推定したものではなく、2種類の**仮定**（ガード多用：JUST10%・PARRY45%・GUARD40%・MISS5%、パリィ中心：JUST30%・PARRY57%・GUARD10%・MISS3%）。固定seedで各240試行。勝率はこのモデルに条件付けられた数字だけで、実際の難易度を断定しない。ガード中の反射ダメージ・時間加速/減速スキル、各遺物の効果、実際の入力遅延、エリア移動、スキル抽選、フェーズ演出の細部は一部省略・近似。

## 注目する検証ポイント
1. 80階終刻の王の通常攻撃を、最大強化時（生命の器Lv6込み）にボス障壁だけで1回耐えられるか。なおHPと障壁の合計に対して大きい通常攻撃は通常通り致死である。
2. ガードを使うと1発は耐えられても、連続しているうちに倒れるか。パリィに切り替える余地が残るか。
3. 60/80階の敵HPが高すぎて、仮定ビルドでも極端な討伐時間を要さないか。
4. 再生力は階層クリア後だけ働き、ボス一戦の中ではHPを回復しないため、耐久評価に二重計上しないこと。
5. 魂増加は死亡報酬を増やすが、ラン内スキル報酬や所持通貨の消費を保証しないこと。

### 80階の重要な解釈

- 最大強化＋例示スキルのHPは275、ボス開始時障壁は55。**HP＋障壁＝330**なので、攻撃力325の通常MISSはちょうど耐えられるが、HPは5しか残らない。次の通常攻撃を無防備に受ければ死亡する。
- 初期障壁96も消費せず持ち込めた場合、障壁は151、合計耐久426となる。連続ガードで生存できる回数は保守条件の**3回から4回**に増える。ただし、この盾の持ち越しは保証できない。
- 80階のガード被ダメージは**98**（敵325×30%を切り上げ）。ガードを続けても通常は敵HPを削れないため、反撃に移らなければジリ貧になる。
- 全JUSTなら最大強化と例示ビルドで60回、無強化でも83回のパリィで倒せるが、これは**全打撃でJUSTに成功し、例示スキルを確実に所持する**理論例に過ぎない。
- 80階の最大強化であってもガード多用型の成功例は0/240。ガードは観察・立て直しの手段だが、ボスの膨大なHPに対して**パリィ成功による反撃を続ける必要がある**設計は残った。

### 設計上の判断と次の調整候補

1. **現時点では敵ステータスの追加変更は行わない。** 耐久と討伐の難しさは確認できたが、実操作でのJUST/PARRY/GUARD/MISS頻度や実際のラン内スキル抽選の分布が分からないため、これだけで適正難度とは断定できない。
2. 防御寄りの救済を重視するなら、**「ガードからの復帰直後のミス」の許容度**を実機検証の優先事項にする。恒久HPをさらに増やすよりも、入力補助・ガード→パリィ移行時の操作感・障壁を補充する機会を先に検証したい。
3. ゲーム内の基礎強化はLv.12まで、再生力なども拡張済み。魂の欠片の**一度限りの救済は合計115個**だが、HP・初期障壁・基礎攻撃・再生・ボス障壁・魂増の最大強化購入総額は**5,801個**。救済は早期進行の補助であり、最大強化へ直接近づく量ではない。
4. 次の評価軸は「実機でガードを何回使ったか」「次の一撃をパリィに切り替えられたか」「実際のスキル取得状態」「何階で詰まったか」。これらを観測してから、再生量・ボス障壁・ガードのダメージ上限の追加調整を検討する。

## 実行
```bash
node scripts/balance-simulation.js
node scripts/balance-simulation.js --json
node --test tests/balance-simulation.test.js
```

手元の追加実機調査をせずに断定的な難度変更は行わない。今回のPRは分析ツールと説明のみで、ゲーム難易度・セーブデータは変更しない。
