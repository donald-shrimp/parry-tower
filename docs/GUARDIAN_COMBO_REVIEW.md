# 守護者の短い連撃：復帰動作の修正

ユーザーより、Devの無敵練習で鐘楼の守護者が「ダン・ダン・ダンダン」から「ダン・ダン・ダッンダッン」のように引っかかるとの報告。音と動きの両方、特にガード・被弾で目立つとの回答あり。

## 確認した原因

拍列 `[2,2,1,3,1,3]` は変わっていない。1.5拍前方式では136 BPMの一拍が約441ms、振り出しは接触約243ms前。一拍の追撃は前の接触から約198ms後に振り始めるが、守護者の復帰は520ms固定だった。

前撃の接触姿勢は約346msまで残り、次の振りが始まっても中間姿勢が抑止される。その後、約41msだけ構えへ戻って再び打ち込み姿勢へ切り替わっていた。旧方式の同じ構造では約16msのため、振り出しを短くした変更で不連続が目立つ。

別に、ガード・被弾の結果音は遅めの入力受付が閉じるまで待つ。補正0/基準スキルでは接触から31ms＋フレーム待ち後に確定し、金属音はそこから約3ms後に予約される。旧方式は接触が拍＋100msだったので受付が接触前に閉じていた。JUST/PARRYと同じ音声経路ではない。

## 今回の修正

短い無振りかぶり追撃に限り、前撃の復帰を `min(元の復帰, max(80ms, 攻撃間隔−振り出し時間))` へ収める。守護者の一拍追撃では約198ms。前の接触姿勢→復帰→次の中間姿勢→次の打ち込みの順に戻し、風切り音の開始時には復帰が終わっている。

長い攻撃、旧方式の復帰時間、拍列、1.5拍前の準備音、追撃の準備省略、接触時刻、入力判定、原画・工房の保存データを維持する。ガード・被弾の結果音の遅れは今回変更していない。まだ入力が来る可能性がある時点で結果音を先に鳴らすと、後から成立したパリィと矛盾するため、音を拍に完全にそろえるには接触音と結果音を分ける等の別設計が必要。
