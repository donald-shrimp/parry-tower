# 本編の重複説明・操作指示の棚卸し

対象：v1.0.1。本編の静的HTML、動的メニュー、報酬、遺物、部屋、イベント、図鑑、ショップ、設定、チュートリアルを確認。Devにある本編共通部分は同じ項目にまとめ、開発専用操作・工房・クレジットは対象外。以下は変更案であり、ゲームの文言は未変更。

判断基準は「何が起きたか・何を得るかを示し、画面から分かる操作を文章で繰り返さない」。費用・確率・取り返せない結果・スキルの比較情報は別扱いとする。

ユーザー確認後の方針：英語小見出しは維持する（C01は削除候補から除外）。分岐カードのSAFE/MYSTERY/DANGER/TRADEは説明文から外し、部屋名の横の色付きバッジにする。ローカル候補をui/route-type-badgesで実装。ほかの文言短縮はまだ候補。

## 一緒に削らない方がよい情報

- 交換時の「取り外した遺物は、このランでは再取得できません。」：取り返せない結果。
- 鏡の「交換が確定するまで、元の遺物は失われません。」：取消可能な時点。必要なら短くできるが、交換元表示との整合が必要。
- 「通常スキル報酬なし・コンボ維持」：分岐を選ぶ損得。
- 「初期装備用」「ラン中の通常抽選は変わりません」：ショップ購入の効力範囲。
- イベントのHP支払いが被弾扱いにならないこと、宝箱/祭器で死亡しないこと、抽選確率、研磨/限界突破の回数制限。
- スキル・恒久強化の現在値と次の値：以前の要望で揃えた比較情報。冗長な文章だけを整理する。
- 新規開始時の中断データ置換、保存失敗、音声停止による一時停止、補正の正負、測定手順と保存前の試し打ち状態：操作画面だけでは分からない情報。
- チュートリアル内のガード/パリィ操作説明：操作を教えるための画面なので、常設説明と同列には扱わない。

## 推奨する順番

まずA01〜A05を短い見出しへ。次にB01〜B09の上下重複を解消。交換画面A06/A07は「新しく得るもの / 手放すもの」を明示してから整理する。英語装飾は維持し、常設の操作説明は最後に判断する。

文言短縮の実装時は本編とDevの共通DOM、動的view、古い中断データからの復帰、コピー検証を合わせて更新する。棚卸し時点では調査のみ。その後、上記ユーザー指定のカードバッジをローカル候補として実装・検証した。
