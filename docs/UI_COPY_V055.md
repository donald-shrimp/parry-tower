# v0.5.5: 文言整理

ゲームの機能、見た目のゲームらしさ、必要な数字・ゲーム内フィードバックは維持し、説明文を削る。

## 取り除く
- タイトルの3行ポエム、冗長なチュートリアル、ON推奨・BPM変化などの説明と「○体遭遇済み」の表示
- ヘッダーの機能アピール、画面下部の技術情報宣伝
- 開始時の「敵が踏み込み…」オーバーレイ
- 戦闘中の「♫ 拍を聴いて構えを読む」「身構え → 踏み込み → 接触」
- 稽古場・一時停止・図鑑・報酬・死亡画面に繰り返し出るアドバイス
- サイドバーの長いHOW TO PLAY文章（パネル自体は残す）

## 維持する
- HP、敵名、階層、コンボ、ビルド、戦績、魂の欠片、図鑑・稽古場入口
- HOW TO PLAYの2行だけの操作案内「リズムに合わせて敵を斬れ！」「画面タップまたはSpaceキーでパリィ」
- タイミング補正は簡潔なHOW TO PLAYパネルの下部に残す
- ジャスト/パリィ/ガード/失敗/レア出現、実際の図鑑登録・討伐報酬などの結果表示
- モーション、全てのBGM/判定・進行・保存・開発者用の階層ジャンプ

本体 `index.html` と開発ページ `dev.html` の共通UIを整理。自動テストで説明文の再混入と既存機能の欠落を検出。
