# キャラクター表示の採用計画

ユーザー了承済みの全立ち絵・モーション、終刻の王の手塗り、最上段「細かめ」のドット加工を本編へ導入する。ゲームルール・音声時計・保存形式を維持して検証し、ローカルmainへマージ済み（`c899839`）。続く「公開して！」でmainのpushとPages公開も明示許可され、CI/デプロイと公開ビルドまで確認する。

## 方針と完了条件

1. 原画座標/関節/手動ポーズを維持した事前加工PNGを既存puppetで描く。細かめは6px・キャラ共通64色。**実装済み**。
2. 王は了承済み工房PNG/編集JSONを固定入力とし、布/冠の自動推測へ戻さない。他11配色は了承状態を維持し、炉心のみ従来の素材/色補正を使う。**実装済み**。
3. 敵の配色IDでキャッシュを分け、起動時は主人公/騎士だけ、出現時に対象敵を準備。最近の4敵へ制限する。確定モーションは同期JSと正本JSONを併用し、工房保存で両方更新する。**実装済み**。
4. 全キャラ/連続出現/欠損時、判定/入力/音声/保存互換、PNG/共通パレット、実ステージ/360px表示、描画コストを検証する。**Node316件/Python6件/実Canvas462描画を確認済み**。
5. 既存の実験ブランチの関連差分をレビューし、コミットして最新origin/mainからローカルmainへマージする。ユーザーの明示許可あり。マージ結果はGit履歴を正本とする。

詳細/再生成は [ADOPTED_ART](./ADOPTED_ART.md)、現状は [HANDOFF](./HANDOFF.md)。新しい主観調整はユーザーの実プレイレビューを受けて進める。旧候補/原画/工房は比較や再編集用に保持する。
