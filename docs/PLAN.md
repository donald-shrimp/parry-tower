1. `game.js` / `character-hero-puppet.js`：成功時だけ剣腕を回す。盾は肩を支点に普段少し下げ、押下100msで既存の接触位置へ起こす。ガード衝突の反動と被弾を分け、敵の接触時計と元画像/保存ポーズを保持する。
2. 入力は全キー/ポインター共通で、受理した試行後300ms＋全入力を離して120msの両条件を満たして再試行。成功時は衝突で300ms硬直を解除、120ms離す条件は保持する。拒否入力でも長押しガードを許し、keyupの重複/複数指/blurで抜け道を作らない。
3. 共通の決定的な金属音合成を追加し、ガード/パリィ/ジャストを低い打音/硬い弾き/明るい余韻で分ける。音は衝突時に1回、既存BGM時計/音声OFFを維持。バッファは初回作成後再利用する。
4. devに無敵試遊と3音の試聴を追加し、任意の敵を繰り返し試せるURLを用意する。通常ゲームの解放条件/セーブを変えない。
5. 連打/再構え境界/長押し/成功後連撃/複数入力/リセット、腕と盾の幾何、音の波形/再利用/衝突時の単発再生、実ブラウザの試遊/360px/試聴を検証する。保存済みポーズと全画像ハッシュ不変も確認し、HANDOFF更新、ローカル試遊版のコミットまで行う。
