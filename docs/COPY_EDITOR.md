# B表の文言エディタ

ローカルで `node scripts/serve-local.js 8016` を実行し、[文言エディタ](http://127.0.0.1:8016/copy-editor.html)を開く。

左でB01〜B12を選び、上段・下段を書き換える。「表示する」を外すとその段を丸ごと非表示にできる。入力内容は残るため、再表示もできる。右側は変更後と変更前の見本。B10はスキル報酬カード、B11はスキンの見出し、B12は遺物/巻物取得後の2場面を用意した。

`{value}` などの差し込みは「数値の見本」を変えて確認できる。ゲームに合わせた値を後から渡すための記号なので、必要な場所へ移動・追加してよい。見本の数値自体はゲームの数値を変更しない。

- 入力の下書き：専用キーでブラウザー内に自動保存。ゲームのセーブとは別。
- 「保存」：`.local-only/copy-editor/project.json` へ保存。直前版は同じフォルダーの `project.backup.json`。
- 「JSONを書き出す」：`parry-copy-b.json` をダウンロード。
- 「JSONを読み込む」：編集データを復元。形式が違うファイルは現在の内容へ適用しない。
- 「この項目を元に戻す」：表示中の項目だけを、短縮前の文言へ戻す。

このファイルはGit対象外。手直しが終わったら「保存」して、採用を依頼する。エディタは本編へ自動適用・公開しない。

B/Cの本編文言は、Bを短縮前へ戻し、C04〜C07だけ短縮を採用。Aの短い見出し、英語小見出し、岐路の色バッジ、岐路最下段の削除は維持する。
