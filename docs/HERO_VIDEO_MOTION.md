# 主人公の剣腕：ユーザー参考動画への対応

## 指示と範囲

参考はユーザーのローカル動画 `C:/Users/EBIHARA/Downloads/sannkou.mp4`（4.9秒、30fps、147フレーム）。ユーザーは「反対の腕は盾を持つ想定で動かしていない。今回直すのは剣を持つ腕だけ」と明示した。盾/胴/脚/マントの既存の動き、反撃240ms、判定/入力/音声/保存は変えない。

動画の主な一周は、頭の後方で構える→前へ伸ばして振り下ろす→下を通す→後ろへ回す→肘を畳んで頭の後方へ戻す。実写の速度をそのまま移さず、この順序を既存の240msへ圧縮した。動画末尾の構えを解いてカメラへ向く動作は攻撃ループへ使わない。動画自体はプロジェクトへコピーしていない。

## 実装

- 既存 `assets/character-hero-puppet.js` の剣腕のみ修整。元PNGを維持し、生成/塗り直しは行わない。
- 元の「剣・手・前腕」を、前腕と「剣・握り手」に分け、手首pivot `[641,343]` を追加。元の画素をマスクで直接使い、上腕/前腕/手首の関節を剛体接続する。手首が動けるため、腕と剣の向きが固定された回転から、剣が腕の後を追う動きへ変更。
- 前方で肩〜肘〜手首が伸び、下への振り抜き、後方での戻しを経て、元の構えへ閉じる。剣の前方360度を維持する。
- 工房に「剣腕の肘から手首」と「剣と握り手・手首」が別々に表示される。7部品の一覧が切れないよう部品表示の行数を追従させ、骨格にも手首を表示。
- 元の `weapon` キーは剣/握り手として維持し、前腕は新しい `forearm` キー。今後ユーザーが腕全体を手動編集する場合は両方を調整できる。既存の保存ファイルは書き換えていない。
