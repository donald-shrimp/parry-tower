# 描画リデザインの使い捨て試作（SVG + Canvas）

## 目的
既存の Canvas 2D 描画エンジン、AudioContext 時計、攻撃時刻、パリィ判定、モーション位置計算、保存形式を一切置き換えず、主人公と **鉄壁の番兵**（`sprite:sentinel` の派生敵を含む）だけを試しに描き直す。

### 実装
- 新しい `assets/characters/hero-body.svg` と `sentinel-body.svg` に胴体・甲冑・マント・兜を描画。
- `assets/character-art.js` が必要時だけ画像をロードし、既存 Canvas に `drawImage`。盾・剣は同じ座標系で Canvas パーツとしてリアルタイムに動く。
- 描画読み込み前／失敗時、対象外の敵は**既存の描画へフォールバック**。
- `assets/game.js` の既存 `hero()` / `enemy()` へ小さな描画分岐だけ追加。戦闘状態・当たり判定・音声・セーブに変更はない。
- 新描画の番兵の剣先は、旧 `ParryEnemyMotions.attackPoint('sentinel', reach, action)` と同じ着弾座標 `(reach,-58)`。

## 見比べ方（ローカル）
```bash
python -m http.server 8000
```
- **新グラフィック:** `http://localhost:8000/dev.html?art=preview`
- **従来グラフィック:** `http://localhost:8000/dev.html`
- 開発ページで「鉄壁の番兵」を選び、開始。主人公と番兵の盾構え・剣先・被弾／パリィを比較。
- 通常入口の `index.html?art=preview` でも主人公のみ常時表示を確認できるが、他の敵は変更なし。
- 切替はURLパラメータだけ。`localStorage` や恒久強化データは使わない。

## 試すこと
1. 主人公の盾構え（100ms）、パリィ時の盾位置と斬撃アニメーション。
2. 番兵の予備動作、着弾時の剣先位置、反動のリズムと見やすさ。
3. `molten_sentinel` など色替え個体に元の `ctx.filter` が効くか。
4. 端末・解像度ごとの SVG 読み込みと視認性。実機の目視確認とスクリーンショットは未実施。
5. 回帰: `node --test tests/*.test.js`。CIの実行結果をPRで確認する。

## 採用／破棄
この変更は独立した実験ブランチと **Draft PR** のみで管理し、`main` にはマージしない。見た目を採用するなら別途レビュー・手直し、却下ならDraft PRを閉じてブランチを削除するだけ。セーブ移行やゲームの巻き戻しは不要。

## 既知の制限
- 身体は1枚の静的 SVG。盾と武器のみパーツ可動。次段階で頭・腕・マントも独立SVGパーツに分離可能。
- この実験では1敵種のみ。ボスや他の敵の形は従来どおり。
- 実機の視覚的比較、アニメーションの録画、アクセシビリティ検査は別途必要。
