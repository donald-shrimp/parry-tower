# v0.9.2 — 押し続けられる盾と後半攻撃力バランス

## 操作
- canvasでポインターダウン、PCでSpace/Enter押下した瞬間だけ、既存の `PARRY_STARTUP=100ms` とタイミング補正を使うJUST/PARRY判定を予約。
- 早すぎた入力は空振りの400ms硬直にはならない。押し続けて**100ms**構え終えると盾が上がり、攻撃着弾時にも保持していればGUARD。短押しして離した場合は防御不能。
- 連続攻撃を押しっぱなしでガード可能。ただし押し直したときだけパリィでき、押しっぱなしで連続パリィはできない。
- ボタンを離すと即座に盾を下ろす。pointerup / pointercancel / keyup / blur / document.hidden / ポーズ / フェーズ転換 / 敵死亡 / 出現時に必ず解除。
- HOLD中は盾を上げたアニメーションと控えめな青い光を維持する。
- 過去のガード成立条件（パリィ直前の24ms幅）は廃止。復帰時の遅押しはMISS扱い。

## 戦闘バランス
- ガード：`min(敵攻撃力 * 0.30, プレイヤー最大HP * 0.40)` の被ダメージ（小数点切り上げ）、障壁を先に消費。
- ガード後コンボ：`max(0, 現在値 - max(5, ceil(現在値*0.20)))`。反撃・吸血・チャージ増加なし。既存の反射スキルは維持。
- ボス攻撃力成長：1–10F 既存1.09、11–30F 既存1.045、31–60F 1.030、61F以降 既存1.012。通常敵も同じ階層曲線。敵HP・リズム・パリィ成功タイミングは一切変更しない。
- 80F終刻の王（精鋭）で攻撃力約325、HP 91,028 を期待。
- 攻撃力の実数値は敵固有倍率で変動。現状の防具や初期HP、スキル取得結果、遺物は既存セーブのまま。
