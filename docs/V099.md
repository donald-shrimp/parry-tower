# v0.9.9 — 戦闘演出・報酬・図鑑の改善

[PR #31](https://github.com/donald-shrimp/parry-tower/pull/31)を、提案一覧だけでなくモック4件の保存コメントと後続QA15件に照合して修正し、ユーザーの公開指示で本編へ採用する。

## 採用内容

- 足元の7粒チャージ、不屈の琥珀輪郭、盾前の氷晶、背後の分身と稲妻、HPバーの障壁表示。
- ボス・精鋭の非開幕3拍以上の強撃に紅蓮Cの予兆。JUST時のHEAVY BREAK報酬。
- 奥義は通常PARRYでも発動するv0.9.8仕様を維持し、暗転・一閃と通常斬撃抑止を採用。フラッシュOFFでは全画面暗転を抑止。
- 採用モックの裏拍とD/A持続和音を開始時から本編・Dev実戦・全11曲試聴へ共通適用。30Combo案は不採用。4拍カウントインと既存の攻撃時計は維持。
- 行商人の複数購入、非戦闘部屋のコンボ維持、血闘の開幕コンボ+3、3イベント追加と連続重複防止。
- 攻撃スキルのスケーリング、初討伐・技量報酬、黄金の直感。塔貨倍率は全イベントにも適用し、説明・結果・獲得累計を統一。
- 聖堂の未取得共鳴相方優先、簡潔な共鳴バッジ、解放と連動するスキル図鑑、ショップ4タブ化。
- 魔物図鑑は26カードに統合し、発見数と保存キーは従来の50個体単位を維持。
- 死亡画面の不要な空振り・最終被弾説明を削除し、「⚔ この敵で稽古」を採用。
- 第一楽章のHP50%保護を追撃でも維持し第二楽章の飛ばしを防止。奥義紋の剛剣二重補正、宝箱の遺物枯渇、中断再開などを修正。

立ち絵原画・保存済みモーション・ユーザー保存キーは維持。公開識別子・asset query・診断・CIをv0.9.9へ、変更済みフォントの識別子を8へ統一する。
