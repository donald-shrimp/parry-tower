# 初心者向けキャラクター調整ツール

**制作・組み込み・検証完了。ユーザーレビュー待ち。** 操作と保存先は [ART_STUDIO.md](./ART_STUDIO.md)。264テストとブラウザ操作で確認し、試験用の調整はリセットした。

## 目的と完了条件

Codexが用意した原画分割・モーションを、ユーザーが日本語GUIで手直しできるようにする。全14敵原画と主人公（15原画）を対象に、画像全体の表示位置と大きさ、部品の位置・回転・中心・重なり・表示、時間ごとの追加ポーズ、切り抜き輪郭を編集する。

- 原画/部品をクリック・ドラッグし、数値でも微調整できる。
- 再生/スロー/時点選択、変更前の位置との比較、Undo/Redo、初期状態への復元がある。
- 下書きはブラウザへ保存。JSONの書き出し/読み込み、ローカルサーバーから専用JSONへの保存に対応する。
- 「保存してゲームに反映」で同じ描画に適用され、再読み込み後も反映する。
- 判定・音声の時計・ゲーム状態を変更しない。編集なしの描画と既存256テストを維持する。

## 実装

1. `character-edit.js` にプロジェクト形式、検証、補間、表示変換、保存の読み込みを集約。
2. 既存3puppetへ小さな編集用フックを追加。既存の元PNG分割と関節解法を共有し、独立したゲーム用レンダラーを作らない。
3. `art-studio.html` と専用CSS/JSで編集UIを作る。画像・部品・切り抜き、時間軸、保存を一画面に配置。
4. 既存ローカルサーバーに、固定の編集JSONだけを保存する同一オリジンAPIを追加。静的ホスティングではブラウザ保存とJSON出力を使える。
5. 検証：プロジェクト/補間/保存APIのテスト、既存全テスト、ブラウザでドラッグ相当の操作・キーフレーム・輪郭・Undo/Redo・保存/再読込・ゲーム反映を確認。

## 境界

既存の原画・作業ツリーは保持する。元のPNGへ描き込まず、調整は別のJSONへ保存する。公開・push・main更新は行わない。未承認の調整を最終採用としない。
