# 回復・障壁ビルドのGUI確認

ローカル v0.9.7-survival-1 をアプリ内ブラウザで確認。停止していた試遊サーバーを再起動し、実際の画面操作・描画・DOM表示で検証した。

## 確認結果

- 追加なし／聖杯／結界増幅／守護の継承／紋章／全部入りの6プリセットを切り替え、80階開始と一時停止を確認。
- 全部入りはHP275・障壁28・補充上限270。継承だけでも障壁28、追加なし／他の個別効果では開始障壁0。新スキルとレリックの説明が対応する。
- GUIの「ガードを1回」で未研磨の全部入りはHP229。「通常被弾を1回」でHP81。いずれも盾を消費し、紋章が使用済みになる。
- 研磨後は聖杯の65%／6%／40%、紋章の50%が説明に反映され、同じ通常被弾でHP126になる。
- PCの主人公／終王の描画、停止／再開、スキル一覧の内部スクロール、レリック説明の折り返しを確認。
- PC通常幅、390×844、320×740で横はみ出しなし。各時点のクライアント幅／内容幅は1318/1318、375/375、305/305。幅変更直後のキャプチャは描画が安定した後に再確認。端末幅設定は最後に解除した。
- 結界増幅のスキル解放画面（RARE・90欠片）と、守護の継承の購入（60欠片→Lv1、次120欠片）を確認。Devの購入・戦闘は通常セーブへ書かない。
- ブラウザの警告・エラーログは空。

## 発見・修正

守護の継承の購入後、Lv1に対して次段階の8%だけが説明されていた。新項目だけを「現在値 → 次レベル値」の表示へ変更。未取得は「最大HP0% → Lv.1：5%」、購入後は「最大HP5% → Lv.2：8%」。再読み込み後のGUIで両方を確認した。戦闘効果・費用は変更していない。

関連Node2件、フォント2件とJS構文検証が成功。前回の全485件の回帰結果は継続して有効で、今回の説明文変更について全回帰は繰り返していない。
