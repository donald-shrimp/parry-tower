# 技術判断

## 2026-10-20：細かめを既定採用し、配色別キャッシュと確定動作を同梱する

ユーザーが最上段の細かめ、全立ち絵/動作、手塗りした王、本編導入/マージを了承。毎フレームの加工や別モーションを作らず、事前加工PNGのパス解決と既存puppetを使う。原画共有の別配色は敵IDで画像/部品をキャッシュし、炉心だけ基本画像/従来フィルタを保持。敵を最大4種類へ制限し、登場しない全素材を起動時に展開しない。王の再生成入力は了承済み書出しPNGと元画像込み編集JSONに固定し、自動領域の推測へ戻さない。

確定した手動動作はJSONと同内容の同期JSも同梱し、初回fetchの成否に依存させない。新しいユーザー編集を優先し、工房保存では両方を更新する。比較/原画工房の入口は分離して残す。詳細 [ADOPTED_ART](./ADOPTED_ART.md)。

## 2026-10-20：フィルタの適用範囲と元画像を別に保存する

ユーザーは素材境界を手塗りで直し、今後の色違いにも流用できる汎用ツールを希望。しわを消す単色塗りではなく、元画像の細部を残すフィルタが必要と明示した。元PNGは編集せず、画素ごとに0（原画）またはフィルタIDを保存する。色相/彩度/明るさ/コントラスト/強さは元画像へ毎回適用し、繰り返し編集しても加工済み画像を重ねて劣化させない。陰影を別の固定パレットへ置換する方式もこの工房には設けない。

フィルタ設定はプロジェクトの複数画像で共有し、範囲は画像別。計算結果をフィルタ単位でキャッシュし、筆の移動では変更矩形だけを合成する。原アルファは合成時に保持。編集JSONは元画像PNGとRLE範囲を含む自己完結形式で、完成PNGとは用途を分ける。下書きは工房専用IndexedDBへ保存し、ゲームの保存や自動画像差し替えを行わない。

## 2026-10-20：色違いは素材別にオフライン再配色し、既存の部品描画を使う

全身hue-rotateでは布/金属/刃が同時に変色し、新しい原画に元の派生設定を反映しにくい。特に守護者は鎧と布が同じ金色のため、色置換だけでは分離できない。原画の色域に加えて独立した素材領域を指定し、素材ごとの明暗ランプへ置換する。関節の所有マスクは素材境界とは別なのでそのまま塗り分けへ流用しない。構え/打ち込みと補修布は同じ配色ルールを使う。

毎フレームの画素処理/マスク描画を避け、加工済みPNGを既存と同じ部品数で描く。候補は原画解像度とドット3種を出し、既定ゲームには採用しない。比較iframeは対象IDを固定したURLで特定の共有原画を候補へ差し替え、旧色相フィルターを外す。キャラ変更で候補iframeを再読込し、共有原画キャッシュの中で別派生の色が混ざるのを防ぐ。これはレビュー用の仕組みで、本編へ採用する際の複数派生キャッシュ設計とメモリ量は別途確認する。

## 2026-10-20：原画座標を保ったオフライン加工を採用前の比較へ限定する

ユーザーは生成ではなく既存立ち絵のドット絵加工と、OK後の採用を指定した。元画像を上書きせず、整数グリッドへの縮小・減色・透明度整理・最近傍拡大を再実行可能なPillowスクリプトで行う。単なるCSS拡大では色数や半透明の輪郭を整理できず、画面全体の低解像度化ではUIや了承済みのエフェクトも変わるため、画像単位の加工を選ぶ。

原画の寸法と座標を維持し、既存の部品マスク/関節/保存ポーズへそのまま適用。構え/打ち込みの色差を抑えるため、キャラごとに共通パレットを作る。3候補を専用ディレクトリに出し、原画/候補のSHAと設定をmanifestへ記録する。比較と動作レビューの任意モジュールだけが候補を読み込む。本編/工房の既定値を変更せず、ユーザーOK前の誤採用を避ける。採用後の画面全体を固定ピクセル格子にする設計ではなく、部品回転時のピクセルの揺れは見た目レビューに残る。

## 2026-10-20：連動編集の回転を共有トラックへ保存する

複数部品の終点を個別の位置・角度へ分解する旧方式では、再生途中の位置が直線補間となり、編集時に保った肘・手首の接続が崩れる。ユーザーは手動グループ回転と同じ軌道の再生を求めている。

v1の任意 `groups` に部品・アンカー・共通中心・移動/回転・キー/適用区間を保存し、既存の個別補正の後に共有剛体変換を適用する。工房/レビュー/実戦が同じplacements処理を使う。終点だけの保存や大量の部品別キー生成では、任意時点の円弧と接続を保証しにくい。IKの導入は今回必要なく、既存の部品編集も維持する。

旧JSONはそのまま読める。グループは保存順に適用され、後から部分集合を編集した場合も先行する変換を保持する。既存の誤った回転値を自動推測して全データを変換せず、今回取得したユーザーポーズのみ見た目を照合して移行した。剣残像は同じ調整済み姿勢の履歴から生成し、未調整の軌道とのずれを防ぐ。
