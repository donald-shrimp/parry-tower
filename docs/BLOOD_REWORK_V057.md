# v0.5.7 吸血・血の律動リワーク

## スキル効果

**🩸 吸血（COMMON / Lv.1〜6）**
- 成功したパリィ1回で、実際に与えたダメージ合計の `(6 + 吸血Lv × 2)%` を回復。
- Lv.1〜6で8/10/12/14/16/18%。
- 実ダメージが正なら最低2HP、ただし1回のパリィの回復上限は最大HPの25%（回復上限が2HPを下回る場合は上限を優先）。
- 最大HPを超える回復はできない。

**🩸🔥 血の律動（吸血＋狂戦士）**
- 現在のコンボ数がそのまま「吸血率」と「一度のパリィの最大HP比回復上限」の双方に加算。
- 1コンボあたり **+1パーセントポイント（%pt）**、上限なし（旧シナジーにあった50コンボ制限と回復倍率は廃止）。
- パリィ成功によるコンボ加算後の値を使う（初回パリィはコンボ1）。
- ガード・被弾でコンボが0に戻ると強化も失われる。
- **計算例**：吸血Lv.1、10コンボ、最大HP100の場合、吸血率18%、回復上限35HP。50コンボなら吸血率58%、上限75HP。

## ダメージ計上・集計タイミング

- 1回の成功パリィに紐づく実ダメージのみを加算し、計算・回復は**パリィ1回につき1回**に限定。
- 通常反撃、落雷、残響、雷鳴残響、ジャスト時の鏡壁、共鳴波、奥義、時空切断、紅蓮処刑など、同期的に生じる直接ヒットは対象。
- 継続炎上ダメージ、ガード反射、被弾は吸血対象外。稽古場でもHP回復しない。
- ダメージを敵の残HPで上限処理し、オーバーキルによる水増しを認めない。追撃前に敵が死亡したら、以降の追撃を追加発動せず、そこまでの実ダメージで吸血。
- 敵を倒したパリィでも回復を成立させるため、致死ヒット時には階層クリア処理へ切り替わる**前に**吸血の集計を確定。
- 音声クロック、敵の攻撃判定、パリィ入力受付時間、死亡後500msの入力無効化、恒久強化の保存形式は変更しない。

## 計算

```text
bonus = 狂戦士あり ? 現在コンボ数 : 0
rate = 6 + 吸血Lv * 2 + bonus
capPct = 25 + bonus
healing = min(max(2, round(実ダメージ * rate / 100)), ceil(最大HP * capPct / 100))
実回復 = min(healing, 最大HP - 現在HP)
```

吸血なし・対象実ダメージ0なら回復0。

## テスト

`tests/game-smoke.test.js` に、Lv別吸血率、最低回復・HP上限、血の律動の50/100コンボ超、パリィ由来の複数ヒット、奥義などの追撃、死亡直前の敵へのオーバーキル、ガード反射と炎上の除外、コンボ断絶、稽古場での無効化を追加。

※今後のバランス調整の対象は吸血率と回復上限の二つの定数。既存プレイヤーのスキルレベルおよび初期スキルの解放状態はそのまま利用する。
