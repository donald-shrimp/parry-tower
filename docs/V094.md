# v0.9.4 — 一点特化と行商人の拡張

## 仕様

- 通常上限：剛剣20、落雷12、灼熱/一点集中/生命の器/魔法障壁10、吸血8、氷結/心眼/静かな呼吸6。他は従来どおり。
- 全24スキルを各挑戦2回まで限界突破可能。現在の上限に到達した所持スキルだけが対象。購入時に上限とレベルを同時に1増やす。恒久育成・次の挑戦には持ち越さない。
- 氷結の軽減率はLv6まで15+10×Lv%、Lv7は80%、Lv8は85%。双撃は最大Lv7で77%。心眼は最大±27ms、静かな呼吸は±55ms。スキン倍率は従来どおり。
- 行商人は訪問につき1品。従来4品に、技の指南書34塔貨（所持スキルを指定して+1）、限界突破の秘伝書60塔貨、奥義の霊薬18塔貨（ゲージ+3、最大7、次の成功パリィで発動）、遺物の研磨剤36塔貨を追加。価格は初期バランス案として採用。
- 指定商品は対象選択まで無料。選び直し可能。確定時に資格と残金を再検証し、一度だけ支払う。選べる対象がない商品は無効化する。
- 遺物は各個体1回だけ研磨可能。発動条件・欠点は保持して主効果を強化。研磨は挑戦限定、交換した遺物からは取り除く。強化前後の効果を購入前に表示する。
- Devに育成途中/上限到達の行商人セットを用意し、本番セーブへ書き込まず購入・次の戦闘まで試せるようにする。
- 承認済み画像・モーション・BGM・効果音・既存セーブ形式を維持。本番v0.9.4として検証、main統合、公開まで実施する。

緩慢の呪いは従来のLv1–4の拍単位効果を維持し、突破Lv5/6でそれぞれ+1拍ずつ延長する（合計+3/+4拍）。拍から外さず毎回の突破を有効にする。初撃・再開時の4拍カウントインは保持。既存の%表記を実際の拍数へ、奥義紋の%表記を既存の基礎ダメージ加算値へ訂正する。
