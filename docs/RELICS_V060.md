# v0.6.0 — 遺物（レリック）システム（Draft PR）

## 基本ルール

- **1ランで所持できる遺物は最大3つ**。スキルとは別枠で、レベル・恒久購入・恒久封印の対象外。
- 同じ遺物は重複取得できない。3つ所持後は新しい遺物を選択して**任意の所持遺物と交換**するか、獲得を見送る。
- 取り外した遺物は同じラン中に再登場しない（`relicDiscarded` で追跡）。
- 通常の階層クリア報酬（スキル3択/4択、引き直し、HP20%回復）は従来どおり残る。レリックが出現した階では**レリック選択→通常の戦利品選択**の順に表示する。
- 遺物状態は戦闘ラン内メモリのみに存在する。現行 `parryTowerPermanent_v1`、`parryTowerPrototype_v1`、図鑑データの永続形式は変更しない。タイトルに戻ったときや次のランで消滅する。
- 稽古モードではレリック効果は無効。開発者テスト画面も既存の保存隔離を維持する。

## 入手判定（1階層につき最大1回）

| 倒した敵・階層 | 入手 |
| --- | --- |
| **3F** | 初回確定 |
| **5Fのボス** | 確定 |
| **10F以降、5Fごとのボス** | 確定 |
| 精鋭 | 20%で遺物報酬 |
| レア敵 | 35%で遺物報酬 |
| 通常敵 | なし |

当該の階層や敵を倒したあとでのみ判定する。優先順位は3F → ボス → レア敵 → 精鋭。

3種類の異なる遺物を候補に選ぶ。各候補の希少度抽選の重みは以下。すでに所持・破棄した遺物、あるいは希少度の候補が尽きていたら、**選択可能な残りの希少度に重みを再配分**する。全候補が尽きていたらレリック画面は省略し、通常のスキル報酬に進む。

| 報酬種別 | 風化（COMMON） | 秘宝（RARE） | 神話（LEGENDARY） |
| --- | ---: | ---: | ---: |
| 3F | 80 | 20 | 0 |
| 5Fボス | 65 | 35 | 0 |
| 10F以降のボス | 45 | 45 | 10 |
| 精鋭・レア敵 | 60 | 40 | 0 |

## ダメージ・回復・防御処理の規則

- レリックによる直接追撃（雷導石・雷帝の導線・二重奏の仮面）は、既存の `damageEnemy()` を通す。成功パリィの範囲に入るため吸血の**実際に奪ったHP**へ合算する。オーバーキルは吸血対象外。
- 雷帝の導線は落雷・残響共鳴雷撃・過充電・雷導石の雷撃と追加雷撃を強化。独立した雷導石は落雷・過充電の所持を要求しない。
- 巡礼者の鐘・血盟の杯の実HP回復は、成功パリィの回復確定時に合計し、血の渇望の**次の反撃への実回復変換**にも含める。満タン超過分は変換しない。血の渇望の既存攻撃上限を維持し、無限連鎖を防ぐ。
- ガード・被弾由来の反射ダメージは吸血対象外。銀鏡は障壁・氷結の軽減後のHPダメージに適用する。
- 死神の盟約の最大HP補正は実数値から再計算し、生命の器を取得した場合も再適用する。解除時にはHPを自動回復させない。
- 雷導石などの発動準備がとどめの反撃で未消費になった場合、次階に持ち越して次のパリィで発動する。HP被弾後の血盟の杯の回復準備も次の成功パリィまで保持する。
- レリックによる追加ヒットが新しい成功パリィイベントを発火させない。BGMクロック・JUST/通常パリィ判定・デバイス入力はそのまま維持する。

## 実装構成

- `assets/relics.js`：レリック定義、既所持・破棄済み除外、希少度加重候補、階層別入手判定。
- `assets/game.js`：戦闘ラン状態、イベント処理、報酬→通常戦利品の2段階遷移、付け替えと状態後片付け。
- `index.html` と `dev.html`：専用レリックモーダル、既所持3枠一覧。
- `assets/style.css`：PC・モバイル対応のカードと交換画面。
- `tests/relics.test.js` と `tests/game-smoke.test.js`：カタログ、希少度・入手判定、全15効果、交換、吸血・血の渇望、旧データ保存隔離、死亡/次ラン初期化を検証。
