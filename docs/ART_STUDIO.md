# キャラクター工房

色の適用範囲を手塗りする場合は、別の [フィルタ塗り分け工房](./FILTER_PAINT.md) を使う。任意画像に複数フィルタを設定し、元のしわ・陰影を残したまま範囲ごとに色味を変えられる。位置/モーション編集とは独立している。

主人公は参考動画に合わせ、剣腕を「肩鎧・上腕」「肘から手首」「剣と握り手・手首」の3部品で編集できる。盾と左腕は独立して維持する。腕全体の位置を変えるときは3部品を確認し、手首からの剣の向きだけを変えるときは「剣と握り手・手首」を選ぶ。

Codexが作った大枠から、気になる位置・部品・動きを手動で直す日本語GUIです。14敵原画と主人公を編集でき、敵の色違いは同じ原画の調整を共有します。

## 開く

内側のリポジトリ `C:/Users/EBIHARA/Downloads/parry-tower/parry-tower` で起動します。

```powershell
node scripts/serve-local.js 8002
```

<http://127.0.0.1:8002/art-studio.html>

Node以外のインストールやビルドは不要です。既存8000番のサーバーはそのまま残しています。専用のファイル保存も使う場合は8002番を使ってください。

## 最初の調整

1. 左上でキャラクターを選びます。「画像全体」はキャラの表示位置と大きさです。
2. 部品一覧、または絵のダブルクリックで部品を選びます。ドラッグで位置を直せます。矢印キーは1px、Shift＋矢印は10pxです。数値は原画の画素を基準にしています。
3. 部品は一覧の上ほど手前。「手前へ」「奥へ」で重なり順を変え、丸い表示ボタンで表示/非表示を切り替えます。
4. 右の「回転中心」を選ぶと、黄色い点のドラッグで中心を変えられます。「回転」では絵の周りをドラッグして角度を調整します。位置・角度・大きさ・不透明度は数値でも直せます。
5. 上の「一人で編集」を「実戦の配置」へ切り替え、下の「接触」で剣と盾の位置を確かめます。主人公は反撃の時間軸です。

## 動きを変える

1. 部品を選び、時間を止めて「この時点のポーズを編集」をオンにします。
2. 位置や角度を変えると、その時点へポーズが記録されます。最初と最後にも基準のポーズを置き、間を自動でつなぎます。記録したポーズは下の菱形を押して選べます。
3. 基本設定は動作全体への調整、ポーズ編集はその時点への追加調整です。「大きく振る」「ぐるっと一回転」「ゆっくり揺らす」から試すこともできます。
4. 「元の動きを止め、自分のポーズだけ使う」をオンにすると、その部品を元の構えに戻して自分のポーズで動かせます。前腕・剣などは別部品なので、必要に応じてそれぞれ直します。
5. 次のポーズへ「なめらか」「同じ速さ」「次まで止める」を選べます。再生は1倍/0.5倍/0.25倍です。

元の攻撃や音声の時刻は変わりません。表示の調整なので、「実戦の配置」と接触ポーズで見え方を確認してください。

片手剣の大枠はv5、両手持ち4体はv6です。両手持ちは「構え」と「打ち込み」の作画を切り替えます。「打ち込み専用の上半身・両腕・剣」を選ぶと接触の1500msへ移動し、その絵の位置・回転・切り抜きを直せます。構えの部品を選ぶと、必要に応じて待機へ戻ります。打ち込みの腕は一枚の作画として形を保つため、その時点の肘だけを別々に曲げる編集はしません。保存JSONは引き続きv1で、旧ファイルは自動変換や上書きをしません。

[動作レビュー](http://127.0.0.1:8002/art-preview.html?enemy=guardian&time=1500&compare=source#stages) では構えの原画と打ち込みを並べられます。「部品を見る」内には、それぞれの原画へのリンクもあります。手動調整のあるキャラは、調整前の剣の位置に残像が出ないよう、基準モーションの軌跡を表示しません。

## 切り抜きを直す

部品を選び、「切り抜き」へ切り替えます。原画の上の点をドラッグするか、「輪郭を描き直す」で3点以上置いて確定します。離れた部分を同じ部品へ含める場合は「別の範囲を追加」を使います。

部品同士で重なる画素は既存の分割優先順で割り当てます。手前/奥の順は表示の重なり順です。胴は分割後に残る画素で、騎士の赤い飾り布は補修済み画像です。この2種類は位置と動きを調整します。

## 保存と引き継ぎ

- 下書きはこのブラウザへ自動保存します。「元に戻す」「やり直す」、部品/キャラのリセットも使えます。
- **保存してゲームに反映**：ローカルサーバーでは `assets/character-art/studio-project.json` へ保存し、同じブラウザにも反映します。直前のファイルは `studio-project.backup.json` へ残ります。「実戦で確認」は調整を読む実戦を開きます。
- **調整ファイルを書き出す/読み込む**：JSONとして保管・復元できます。保存データはCodexも読み取れるため、次の修整へ引き継げます。
- 静的サーバーではブラウザへの反映とJSON書き出しを利用できます。画面の保存結果にファイルへ保存できたか表示されます。

元のPNG・元の骨格データは書き換えず、調整を別データへ保存します。ブラウザの下書きとファイルでは、更新日時の新しい方から再開します。複数端末で続ける場合はJSONを書き出して読み込んでください。

# 残像の速さを変える

鐘楼の守護者を選ぶと、右側に「剣の残像」→「残像が追いつく時間」が表示される。40〜400msのスライダー/数値入力で調整し、短いほど速く追いつく。「速め・80ms」「標準・200ms」ボタンもある。再生で確認し、右上の「保存してゲームに反映」で保存。Undo/Redo、下書き、JSON入出力にも対応。派生キャラは同じ原画の設定を共有する。

保存は既存v1のキャラ設定に任意の `effects.swordBlurDuration` を追加する。旧JSONはそのまま読め、省略時は200ms。残像だけの設定で基礎描画を抑制しない。画像全体の移動/拡大、打ち込み専用上半身の位置/回転/拡縮/不透明度にも残像が追従する。判定時刻は変わらない。


## 中割りの腕だけに調整を適用する

守護者を選び、右側「中割りだけを直す」の「今の調整を中割りだけに適用」を押す。調整された両腕と剣をまとめて対象にし、1390msへ移動する。基本設定の移動/回転と、記録済みキーの移動/回転の両方を中割りの間だけ反映する。既存の数値やキーを移し替えないため、中割りの現在の見た目は保たれる。全体の位置、胴/脚、切り抜き、拡縮、回転中心、不透明度は変更しない。

適用した腕の表示は「中割りだけ」。その後も中割りで位置・角度を調整できる。「この時点のポーズを編集」も併用でき、区間外への位置/角度補正は0になる。「動作全体への適用に戻す」で解除でき、適用/解除はUndo/Redoへ対応する。右上「保存してゲームに反映」でファイルへ保存する。

v1の部品設定に任意 `poseWindow: [開始, 完全適用開始, 完全適用終了, 終了]` を追加。守護者は `[1276.8, 1377.6, 1420.8, 1421]` ms。開始前/終了後は位置・角度補正0、完全適用区間は1、その間をsmoothstepでつなぐ。未指定の旧データは従来どおり全時間へ適用。281テストと実GUIの適用/Undo/Redo/保存を確認した。

## 複数の部品を連動させる

左の「両腕＋剣」または「剣側の腕＋剣」を押す。好きな組合せは、各部品のチェック、またはShift/Ctrl＋クリックで選べる。通常の部品名クリックは1個だけの編集へ戻る。「選択を解除」で画像全体へ戻る。

複数選択中は、キャンバスのドラッグや矢印キーでまとめて移動する。右の「まとめて左右」「まとめて上下」「まとめて回転」も使える。数値は選択後の変更量で、選び直し/時点変更/Undoで0へ戻る。「回転」は黄色い共通中心を基準に、選んだ部品同士の位置関係を保って回す。「回転中心」でキャンバス上の点をドラッグすると中心を置き直せる。初期中心は最初に選んだ部品の回転中心。プリセットの初期中心は剣側の肩。

「変更する範囲」で中割りだけ/この時点のポーズ/動作全体を選ぶ。守護者のプリセットは中割り1410msへ移動し「中割りだけ」が初期値。主人公は剣腕3部品だけを選び、盾腕を含めない。グループ操作は部品間の相対位置を保つもので、肘を自動で曲げ直すIKではない。腕だけ曲げ直すときは対象を絞り、肘などへ共通中心を置く。

1回の操作をUndoでまとめて戻せる。連動操作は、部品の組合せ・共通中心・移動量・回転量をv1の任意 `groups` トラックへ保存する。選択表示は一時状態だが、回転の中心と軌道は保存され、工房・レビュー・実戦で同じように再生される。非表示姿勢を混ぜた場合や中割り区間外での操作は案内を表示して止める。変更量0やフォーカスだけでキーを追加しない。

283テスト、GUIの一括移動/回転/中心変更/矢印/部分選択/キー/Undoを検証。書き出しを実レンダラーで照合し、5部品の移動・共有中心の回転と中割り外の維持を確認した。

守護者の中割りの初期姿勢は、追加指定で溜めと同じ腕の形へ戻した（既定の前方90度回転は解除）。「中割り」1410msや連動選択は引き続き使えるので、この形から一緒に動かして姿勢を作れる。

### 連動した形のままアニメーションする

守護者の「中割りだけ」の連動操作は、1340msまで溜めを保ち、1410msの調整姿勢まで70msで共通の中心を使って円弧で動く。中割りは1420.8msまで約11msだけ保ち、振り下ろしの作画へ切り替わる。中割りボタンや守護者の一括選択も1410msへ移る。部品別の位置を直線補間しないため、両肘・手首・剣のつながりを保つ。以前の部品単位の中割り補正区間は互換性のため維持する。

回転ドラッグは±180度の境界をまたいでも短い方向へ連続する。意図して一周させる操作は累積回転として残る。守護者の剣の残像は、調整後の剣が実際に通った軌道へ追従し、作画切替の後も最後の構え位置から追いつく。残像の速さは従来の「残像が追いつく時間」で調整できる。

288テスト成功。共有中心の円弧、任意中心での追加操作、角度境界、守護者の全区間の肘・手首、調整後の剣残像、旧JSON互換と保存を検証。実GUIで1倍/0.25倍再生、境界をまたぐ回転とUndo、保存・再読込を確認。証跡 `test-results/linked-animation/`。
