# パリィの塔 v1.0.2

イベント・報酬画面の文言と岐路カードの表示を整理しました。

- 岐路のSAFE / MYSTERY / DANGER / TRADEを部屋名横の色付きバッジへ移動。重複する最下段の説明を削除。
- 秘伝の巻物や遺物などの見出しを整理。英語の小見出しは維持。
- 聖堂の選択を「歌うように祈る」「一心に祈る」「静かに祈る」に変更。共鳴の説明から「ランダムに」を削除。
- 保存済みの編集内容を金床・祭器へ反映し、報酬カードの現在効果と次レベル効果の重複を整理。
- スキン画面の重複見出しを削除し、戻る・進むなど一部ボタンの表記を統一。
- 新しい文言の文字を表示フォントへ収録し、分離済みの画面・スキル定義もフォント検査対象へ追加。
- 開発用の[文言エディタ](./COPY_EDITOR.md)を追加。編集・保存はローカルで行い、本編へ反映する際は別途コードへ採用。

戦闘・抽選・報酬量の仕様と保存形式は変更していません。以前の中断データに残る旧見出しも表示時に整理します。
