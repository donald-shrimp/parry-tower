ユーザー了承済みの現行1曲＋新曲7曲を本編へ採用。1〜10Fは現行曲、以降は10階ごとのエリアに合わせて自動切替する。81F以降は既存のエリア巡回と同じ順で繰り返す。Devで全曲を聴き比べられる。

- ステージを選び「BGMだけ再生」。通常112 BPM/ボス136 BPMを比較できる。
- 「この曲で無敵練習」は、そのエリアの通常敵/ボスを使う。記録を書き込まない。
- 試聴中は拍と8小節内の位置を表示。「停止」/タイトル復帰/画面非表示で停止する。
- `music=chapel` などのテーマID、`musicMode=boss` で開始時の選択を指定できる。自動再生はしない。

## 現行曲の仕組み

録音MP3やMIDIファイルはなく、`assets/game.js` の `playMusicStep` がWeb Audioで音を合成する。毎回ランダムに作曲するのではなく、決まったパターンを繰り返す。ノイズの波形だけは生成する。

1. 1小節4拍を8分音符8ステップに分ける。
2. キックは低い正弦波と音程の下降、スネア/ハットは帯域を絞ったノイズ。ベースは鋸歯状波、旋律は三角波、長い和音は正弦波。
3. 音符ごとに周波数・音量・長さ・波形を指定する。通常の根音番号は `[0,5,3,2]`、ボスは `[0,3,2,5]`。2小節ごとに次へ進み、8小節で戻る。旋律は主に2拍目/4拍目の裏へ置く。
4. 通常112 BPM、速い敵124 BPM、ボス136 BPM。`AudioContext.currentTime` を基準に170ms先まで小刻みに予約する。

攻撃の譜面は `assets/encounters.js` の各敵の `rhythm` 配列。騎士の `[2,2,3,1]` は、前の攻撃から2拍、2拍、3拍、1拍という間隔の繰り返し。`1.5` は1拍半。BGMの音を解析しているわけではなく、同じ時計の原点/1拍の長さから音と攻撃時刻を計算する。音量や音色を変えても判定を動かさない。

## 実装と採用範囲

- `assets/stage-music.js`：凍結した譜面データと、副作用のない8分音符イベント生成。タイマー/音声/保存を持たない。
- `index.html` / `dev.html` がゲームより先にこのモジュールを読み込む。既存のエリア定義から曲を選択し、地下墓地だけは現行の `playMusicStep` 経路をそのまま通る。
- 新曲も既存の `scoreTone` / `scoreNoise` / BGM時計を使う。鐘は3つの正弦波の倍音、反響は半拍遅れの小さな音で表現する。
- 試聴だけのモードは戦闘を進めない。練習へ移ると試聴を止め、戦闘の拍原点を通常どおり設定する。
- 切替時は古い曲のBGM Gainをフェードアウトして切り離す。長い音を新しい曲へ持ち越さない。
- 音楽を切り替えても、敵のリズム配列・112/124/136 BPMの区別・判定窓・採用済み効果音の音量を変えない。

ユーザーの実音レビューで全曲採用が承認された。Devの通常起動も階層に従い、試聴室の「この曲で無敵練習」だけは選択した曲を指定する。BGMマスター音量.35、判定、保存、効果音25%を維持する。
