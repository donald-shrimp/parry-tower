# パリィの塔 / Parry Tower

**音楽を聴き、敵の構えを読み、刃を弾く。** ブラウザで遊べる、リズム＋モーション型のパリィ・ローグライトです。

- **公開安定版:** v0.7.1（ビルド診断・キャッシュ整合性検知と安全な再読み込み案内）
- **操作:** スマホは画面をタップ、PCはクリックまたは Space
- **特徴:** Web Audio APIで生成するBGMと敵の着弾時刻を同期。敵別の攻撃パターン、稽古場、ジャストパリィ、3択強化、シナジー進化、無限階層、恒久強化。
- **v0.5.3追加済み:** 10階ごとに変わるエリア、固定＋抽選の敵、精鋭個体、希少敵の魂の欠片ボーナス、出会って埋める図鑑、遭遇済みの敵だけを練習できる稽古場。
- **外部依存:** なし（ビルド不要、CDN不要）

## 遊び方

[GitHub Pagesでプレイする](https://donald-shrimp.github.io/parry-tower/)

ローカルでは `index.html` をブラウザで開くだけで動きます。BGMの再生はブラウザの制約により「開始」などのユーザー操作後に始まります。

1. 敵の構え・BGMの拍から着弾を予測する。
2. 剣や身体が盾に接触するタイミングに合わせてタップする。
3. 戦闘に勝利してスキルを選び、ビルドを育てながら塔を登る。
4. 稽古場で敵ごとのタイミングを練習する。タイミング補正は端末ごとに調整する。
5. v0.5.3では塔の敵に**遭遇した瞬間**に図鑑登録。倒せずに負けても、次からタイトルの「図鑑・稽古場」でその敵のタイミングを無敵で練習可能（報酬なし）。

## 構成

```text
index.html                 ゲーム画面のDOM
assets/style.css           UI・レスポンシブCSS
assets/game.js             ゲーム、描画、音楽とパリィ判定
assets/encounters.js       階層ごとの出現ルール、レア・精鋭、遭遇図鑑のデータ定義
assets/progression.js      恒久強化の費用・保存形式・初期スキル装備の検証
tests/                    出現ルール・恒久強化・ゲーム画面の状態遷移を検証するテスト
.nojekyll                  GitHub Pages静的配信設定
.github/workflows/check.yml  構文と静的ファイルのCI
docs/ARCHITECTURE.md       同期方式と改修時の注意
```

`assets/game.js` はv0.5をベースに、v0.5.2でパリィ成功時の青白い閃光・衝撃波・音楽的な効果音・敵の反動を追加したものです。パリィ判定（ジャスト±11ms／通常±31ms）、BGM同期、入力タイミングは維持しています。過去のv0.1〜v0.5はGitタグで保存しています。

## 今後の進め方

変更はブランチとPull Requestで管理し、音声クロック・モーション・判定の同期を壊さないことを最優先とします。次の課題候補は、楽曲アレンジ、敵モーションの洗練、リズムの公平性、入力遅延の実機検証、強化バランス調整。

## セーブとプライバシー

セーブデータと音声タイミング補正はブラウザ内の `localStorage` に保存されます。外部送信は行いません。`file://` で遊んでいたデータは、GitHub PagesのURLとオリジンが異なるため**自動では引き継がれません**。今後データ移行機能を検討します。

## ライセンス

現時点ではライセンス未設定です。GitHub上で公開されても、再利用・再配布の許諾を意味するものではありません。外部コントリビューションを募集する前に方針を決めます。


## v0.5.6：恒久強化・初期スキル装備

PR #11 で公開済み。スロット2枠の購入、全18種類の個別解放、装備変更、階層突破後の回復・ボス開始時の障壁・魂の獲得増・引き直し・4択・1回復活、専用の「恒久強化・装備」画面を追加しました。

## v0.5.8：新スキルと運命の封印

新スキル6種類「不屈・拍動・過充電・血の渇望・氷結・王の一撃」と専用シナジー6種類を追加し、合計24スキル・11シナジーに拡張。

## v0.6.0 — 遺物（レリック）

1ランだけ有効な**遺物15種類**（風化6・秘宝6・神話3）を追加。所持上限3個、重複所持なし。

- **3F初回、5Fごとのボスは確定入手**。精鋭は20%、レア敵は35%で追加チャンス。報酬は3択。
- 所持3枠が埋まったら、今ある遺物と**交換**するか見送る。外した遺物は同じランで再取得できない。
- レリックを選んだ後でも、従来のスキル取得・回復報酬を選べる。
- 新しいRELICSパネルに取得済みと効果を表示。スキルと組み合わせると雷撃・炎上・吸血・コンボ・ジャスト・障壁・奥義が変化する。
- レリックは出撃ごとにリセット。旧セーブ、恒久強化、運命の封印、稽古・開発者モードの保存互換を維持。

具体的な効果・抽選率・処理順は [v0.6.0 遺物仕様](docs/RELICS_V060.md) を参照してください。

**v0.6.0で公開。** 実装の詳細は [PR #15](https://github.com/donald-shrimp/parry-tower/pull/15) を参照してください。GitHub Pagesへの反映には少し時間がかかる場合があります。

## v0.7.0 — 塔の岐路

10階ごとに2回、4Fと8Fを**通常戦闘を置き換えるイベント階層**に変更。岐路でどの道を選ぶかによって、安全な回復・商人による買い物・精鋭との血闘・ランダムな奇遇イベントが発生します。

- **4F：**🔥安息・🛒行商人・⚔️血闘。**8F：**🔥安息・🔮奇遇・⚔️血闘。14F/18F以降も同じ周期。
- 新通貨**🪙塔貨**を討伐で獲得（通常6／精鋭・レア12／ボス10／血闘14）。魂の欠片とは独立し、ラン終了で消滅します。
- 行商人は訪問ごとに1商品を購入。引き直し・障壁・スキル・レリックの4品。
- 奇遇4種：血の祭壇、忘却の鏡、旅人の遺品、封じられた宝箱。
- 非戦闘ルートはスキルの通常報酬を得られずコンボも途切れますが、HP回復や塔貨・強化が選べます。血闘ではコンボ維持と通常スキル報酬を狙えます。
- 5F/10Fのボス・3F初回レリック・9F固定精鋭・既存セーブ形式はそのまま。

[詳細設計と効果値・例外仕様](docs/ROUTES_V070.md)

## v0.7.1 — 診断とキャッシュ整合性チェック

友達と遊んでいるときに、HTMLは新しいのにブラウザが古い `game.js` を利用して、**塔貨が増えない・分岐が発生しない**ことが疑われるため、独立した診断モジュールを追加。

- ゲーム画面のConsoleで **`parryTower.diagnose()`**：HTML / JS ビルド、読込済みモジュール、現在の階・ゲームモード・塔貨・累計獲得塔貨・分岐予定、稽古状態を表示。
- 共有可能なJSONは **`parryTower.report()`**。**localStorageの保存内容、個人情報、認証情報は出力しない**。
- 独立した `assets/diagnostics.js` を `game.js` より先に読み込み、ゲーム本体からビルド識別子と状態取得APIを登録。古い `game.js` やロード失敗で登録されない場合にも、HTMLバージョンだけを信用せず警告。
- 各JavaScript・CSS URLへ `?v=v0.7.1-1` を付け、HTML更新時にキャッシュされた古いJS/CSSとの混在を防止。今後更新するときはHTML内のビルド識別子・ゲーム本体・診断モジュール・アセットクエリを同時に変更する。
- 不一致ならページ上に警告を表示し、**手動の「再読み込みする」ボタン**を出す。自動リロードやlocalStorage削除は一切行わない。**途中のランは再読み込みで失われる**ので警告に明記。
- `index.html` と `dev.html` の両方で利用可能。独立した診断テストでは古いgame.js、HTML/JS不一致、モジュール欠落、ロードエラー、正常起動、再読み込み要求などを検証。
